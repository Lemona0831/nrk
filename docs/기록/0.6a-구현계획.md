# 0.6a 구현 계획

기획서 11절(0.6: 3챕터 캠페인)의 첫 단계인 0.6a를 만드는 순서다. 0.6a는 0.6의 모든 시스템과 1챕터를 담는다. 보스·강적 상세는 저장소 밖 비공개 문서(nrk-private/보스.md)를 따른다.

## 순서를 이렇게 잡은 이유

- 화면(1)을 앞에 둔다. 위험이 낮고, 이후 모든 화면이 새 테마 위에서 만들어진다.
- 저장(2)과 장비 바탕(3)을 아이템 효과(5)보다 먼저 한다. 장비가 한 곳에만 있는 규칙(9.2절)이 흔들리면 100종을 넣은 뒤에 고치기 어렵다.
- 전투 규칙(4)을 아이템보다 먼저 바꿔 새 기준선 승률을 잰다. 그래야 아이템이 균형을 얼마나 바꾸는지 따로 볼 수 있다.
- 자동 테스터는 단계 0에서 나눈 파일을 읽게 고치고, 단계 11에서 새 판 구조에 맞게 다시 쓴다. 그사이에는 B0.5 방 구성으로 전투 규칙만 잰다.

## 진행 기록

- **단계 0 (10월 2일):** `next/`에 B0.5를 복사하고 데이터를 `next/data/` 다섯 파일(enemies, classes, items, rooms, changelog)로 나눴다. 나누기 전후 자동 테스트 960판 결과가 완전히 같다. 브라우저 저장 키와 저장소 경로를 B0.5와 나눴다. 테스트 도구는 next/를 읽는다.
- **음악 (10월 2일, 단계 1 일부):** 만든 사람이 준 곡 4개와 효과음 1개를 웹용 MP3 96kbps로 줄이고 음량을 맞춰 `next/audio/`에 두었다(127MB → 39MB). 첫 화면·던전·보스·상점마다 곡이 바뀌고, 처음 누를 때 시작한다. 상단 "설정" 버튼으로 여는 설정 창에서 소리 켜기·끄기, 음악·효과음 음량, 설명 창, 적 차례 진행 속도를 바꾼다(전투 중에도 열린다). 곡은 모두 무료 소스다(만든 사람 확인). 원본 `bgm/`은 저장소에 올리지 않는다.
- **단계 1 (10월 2일):** 어두운 테마 하나로 바꿨다(11.10절 토큰, 글자 대비 모두 4.5:1 이상, 흐린 글자가 가장 낮은 5.8:1). PC(720px 이상)에서 행동 버튼을 묶음별 세로 칸으로, 고르는 창·설정 창은 화면 가운데로. 설정 창을 한 줄씩 정리하고 켜기·끄기를 스위치로. 등급 색 토큰(`--gr-n/m/r`)과 클래스(`.gr-*`, `.grb-*`)를 미리 둠. 휴대폰 전투 상단 높이 그대로(74px).
- **단계 2 (10월 2일):** 캐릭터 만들기(직업 → 스킬 → 능력치, 이전·그만두기, 끝까지 정하기 전에는 저장 안 함), 쓰러지면 캐릭터 끝(쓰러진 자의 기록, 첫 화면 목록), 이어 하기·포기하기, 새 캐릭터 확정 시 기존 캐릭터 포기 기록. 막힌 문 "아직 들어가지 않기". 상단 정리(설명 창은 설정으로, 로그인은 첫 화면만). 남은 설명 창 닫기. 갈림길·새 보스 전까지 지금 방 8개와 늪의 어머니를 1챕터 자리에 임시로 쓴다.
- **전투 이어 하기 (10월 2일):** 전투 중에 닫거나 처음으로 가도 같은 차례에서 이어 간다. 전투 난수 상태를 숫자(`b.rngS`)로 바꿔 함께 저장하고(같은 수열이라 자동 테스트 결과 그대로), 행동을 누른 순간 그 행동을 적어 둬 돌아오면 같은 결과로 처리한다. 보스를 넘으면 이어 하기 자료를 지운다.
- **단계 3 (10월 2일):** 장비마다 고유 번호·등급·챕터·보너스(`run.inv`, `run.eqU`, `run.bag`), 옮기기는 `equipUid`·`unequipUid`·`discardUid`·`addItem`뿐이고 `gearCheck`로 한 곳에만 있는지 확인. 시작 장비(직업 무기 8, 낡은 갑옷 +10, 낡은 플라스크 30%)와 직업 생명력 −10으로 B0.5와 같은 수치(자동 테스트 결과 그대로). 엔진은 `p.gear`로 무기 피해·최대치·플라스크 회복을 읽는다(`basicBase`, `heavyBase`, `flaskHealFrac` — 비교창도 같은 함수). 장비 창(지금 수치 6개, 칸 7개, 설명과 비교, 가방 12칸, 바꾸는 이유는 접어 둠), 얻을 때 비교, 가방이 가득 차면 버리고 받기, 무기는 다른 무기로만 바꾸기, 전투 중 보기만. 스킬은 만들 때만 정한다(바꾸기 버튼 제거). 기록에 방마다 장비 7칸과 버린 장비.
- **휴대폰 화면 (10월 2일, 지인 의견):** 전투 화면이 한 화면에 들어가지 않으면(앱 안 브라우저) 스크롤되게 하고, 아래에 하단 막대만큼 여백, 좌우 여백은 줄였다.
