# 1~3챕터 완성 작업: 진행 기록

목표 원문은 docs/목표-1-3챕터.md다(10월 5일 만든 사람). 이 문서는 그 목표를 실제로 어떻게 나누어 진행하는지, 무엇을 정했는지, 어디까지 했는지를 남긴다. 작업이 길어 대화가 끊겨도 이 문서만 보고 이어 갈 수 있게 쓴다.

- 상태 표기: **끝**(파일 · 실행 결과로 확인함), **진행 중**, **남음**, **막힘**(만든 사람 결정이 필요).
- 측정값은 날짜 · 판(0.6a.2-n) · 조건을 붙인다. 규칙이 바뀌면 옛 값은 지우지 않고 "무효"로 표시한다.

## 2. 진행 기록

- **10월 5일:** 목표 문서 저장, 조사 시작. 조사 시점 기준값 측정(장비 점검, 점수표, 던전 40판)을 돌렸다.
- **10월 5일 (2):** 작업 방식을 워크플로(여러 에이전트가 나누어 설계 · 검증)로 바꿨다. 동시에 돌리는 것:
  - 1단계 조사: 문서 대조 · 2챕터 자산 · 테스터와 낡은 측정값 · UI 접근성 → 영역마다 독립 반박 검증 → 누락 점검. 결과는 docs/현행-조사.md에 합친다.
  - 3단계 설계: 새 직업 여섯(원소술사 · 수도승 · 마검사 + 해금 셋)마다 관점이 다른 설계 셋 → 심사 둘 → 종합 → 악용 점검. 공개 직업 문서는 docs/직업/, 해금 직업은 저장소 밖 nrk-private/직업/.
  - 4단계 설계: 2 · 3챕터마다 설계 셋 → 심사 둘 → 종합 → 반례 검토. 공개 문서 docs/챕터/, 보스 · 강적 기믹은 nrk-private/.
  - 코드는 조사가 끝난 뒤 고친다(조사 검증이 코드 줄을 대조하므로).
- **순서 결정 (10월 5일):** 목표의 2단계(1챕터 재검증)는 둘로 나눈다. 2a: 지금 직업 셋으로 학습 · 난이도 흐름 분석과 측정 도구 보강(바로). 2b: 직업 아홉이 들어간 뒤 1챕터 수치 맞춤(만든 사람의 10월 3일 결정 "직업을 모두 넣은 뒤 던전 전체를 다시 설계한다"와 맞춘다). 2 · 3챕터 구현은 2b 뒤에 한다(목표: 새 챕터 확장 전에 1챕터 재검증).
- **10월 5일 (3), 1단계 끝 (0.6a.2-40):** 조사 다섯(문서 대조 · 2챕터 자산 · 테스터 · UI 접근성 · 누락 점검)을 독립 검증까지 마치고 docs/현행-조사.md와 부록 docs/조사/에 합쳤다(2챕터 자산 보고서는 비공개 보스 개요를 건드려 nrk-private/조사/). 충돌의 현행 기준 10건을 정했다(현행-조사 6절, 잠정 4건은 만든 사람 확인 필요). 찾은 결함과 문장 어긋남을 고쳤다: 알림이 사라지지 않음, 피 웅덩이 출혈 4배 → 2배, 어둠이 예고를 가리지 않음, 고요(효과 없음) 뽑지 않음, 사냥꾼 · 소환사 · 사수 · 지능 문장, 데이터 문장의 옛 낱말, CLAUDE.md 두 줄.
