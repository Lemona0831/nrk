# 전투 효과음 출처 (06a2, 10월 11일)

> 아래 원본 연결 표는 처음 적용한 이력입니다. 0.7.0-5에서 바꾼 현행 연결과 재편집 내용은 문서 끝에 있습니다.

2. Kenney(Kenney Vleugels, kenney.nl)의 공개 소리 모음 셋에서 고른 CC0 파일: 만든 사람의 파일이 없는 이펙트를 채웠다.

## 변환

ffmpeg(imageio-ffmpeg)로 앞뒤 무음 제거 또는 구간 자르기, 끝 페이드, 음량 맞춤(loudnorm 약 -20 LUFS), 모노 44.1kHz MP3 64kbps. 매우 작았던 원본(ice magic, shield, sword-slash 1)도 같은 맞춤으로 올렸다(변환 뒤 평균 -17.6 ~ -22.6 dB). 파일 31개 합계는 약 136KB다. 불꽃 주문과 흘리기는 맞춘 뒤에도 커서 재생 때 음량을 낮춘다(`VFX_SND_VOL`).

## 쓰는 방식

- 짝은 `06a2/js/59-battle-fx.js`의 `vfxSfxKey`가 정한다. 소리 목록은 `06a2/data/audio.js`의 `SFX`(키는 `b_` + 이름)다. 베기는 이펙트 순번이 홀수인지 짝수인지로 변형 둘을 번갈아 쓴다.
- 레벨 올림 소리는 경험치를 받아 레벨이 오를 때 한 번 난다(`66-dungeon-flow.js`의 `sfx('b_levelup')`, 소리 켜짐과 효과음 크기를 따른다).
- 재생은 `06a2/js/76-sound-render.js`의 `sfxPlay`: 파일을 미리 받아 두고 복제해 재생, 동시에 3개까지, 같은 소리는 80ms에 한 번, 사람이 화면을 누른 뒤에만, 실패해도 조용히 넘어간다.
- 설정의 소리 탭: 소리 켜기와 끄기, 효과음 크기(기존), 전투 효과음 켜기와 끄기(`G.data.audio.bfx`, 없으면 켜짐).
- 소리는 그림 효과(전투 효과 끔 · 약하게 · 보통 · 강하게)와 따로 켜고 끈다. 그림 효과를 꺼도 소리는 난다.
- 화면 편집기의 견본 전투, 설정 창 · 시트가 열려 있는 동안, 숨은 탭에서는 소리를 내지 않는다.

## 10월 11일 사용자 청취 의견 반영

암살자 기본 공격과 강공격의 자동 추가 음원이 둔탁하다는 사용자 의견을 반영했다. 암살자의 찌르기 이펙트는 사용자 제공 `sword-slash 1.mp3`에서 만든 `b_slash`, 강공격 타격과 큰 타격은 `sword-slash 2.mp3`에서 만든 `b_slash2`를 호출한다. 검 베기 파일의 기존 변환·음량을 그대로 쓴다. 다른 직업의 타격·강타 연결은 바꾸지 않았다. 새 음원이나 라이선스 주장은 추가하지 않았다. 교체 후의 어울림은 사용자 청취로 확인한다.

재생 음량 계수가 0인 경우 기본값으로 바뀌지 않게 했고, 재생 중 예외가 나면 동시 재생 수를 반환하도록 고쳤다. 동시 3개·같은 소리 80ms 제한은 그대로다.


## 0.7.0-5 공격·스킬·방어 재편집 [현행]

사용자가 스킬·공격·방어에서 자동 추가 음원이 어색하다고 지적하여 17개를 다시 편집했다. 새 외부 음원은 추가하지 않았다. 기존 사용자 제공 검·흘리기·방패·불꽃·냉기 파일을 바탕으로 짧은 구간을 잘라 필터와 페이드를 적용했다. 둔기·피격음 네 개는 기존 CC0 원본의 낮은 울림을 줄이고 길이를 줄였다.

| 재편집한 키 | 편집에 쓴 기존 파일 | 방향 |
| --- | --- | --- |
| pierce, arrow | slash | 짧은 검 찌르기·공기를 가르는 소리 |
| ctr | ppr | 짧은 금속 반격 |
| sp_blood, dot_blood | slash2 | 검 타격 계열 |
| sp_arcane, sp_shock, wgain, heal | sp_frost | 냉기 마법의 짧은 변형. 알림음·글리치음을 제거 |
| sp_venom, dot_venom | sp_fire | 불꽃 마법의 짧은 변형. 물방울 알림음을 제거 |
| pwd, brk | pgd | 방패의 짧은 충격. 유리 충격음을 제거 |
| blunt, big, phit, phit_big | 각 기존 파일 | 저음 정리·짧은 페이드 |

재편집 파일은 모노 44.1kHz MP3 96kbps이며 목표 음량은 -24 LUFS, 최대 피크 -2 dBTP로 설정했다. MP3 디코딩으로 확인한 최대 음량은 -2.2~-9.3 dB, 실제 재생 길이는 약 0.12~0.62초다. 전투 효과음 31개를 브라우저 AudioContext로 디코딩했다. 이는 파일 오류·길이·피크 확인이며 청취 품질 평가가 아니다. 새 변형이 원소·행동 분위기에 어울리는지는 사용자 청취가 필요하다.

검과 화살은 큰 피해를 줘도 주먹 강타음으로 바뀌지 않는다. 암살자·마검사의 근접 공격에는 검 소리를 유지한다. 상태 부여와 속성이 없는 지속 피해에 반복되던 알림음은 재생하지 않는다. 방어·보호막·회복은 재생 음량도 낮췄다. 사용자 제공 베기·화염·냉기·흘리기·방어 원본 파일 자체는 유지했다. 동시 재생 3개, 80ms 간격 제한, 전투 효과음 끄기는 그대로다.
