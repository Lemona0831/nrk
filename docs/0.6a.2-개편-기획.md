0.6a.2 스킬 시험판(`06a2/`, https://lemona0831.github.io/nrk/06a2/)에서 직업, 스킬, 상태이상, 막는 수단, 적, 아이템, 1챕터 무대를 새로 짜는 개편이다. 진행 골조(캐릭터 만들기 → 챕터 던전과 갈림길 → 야영지·샘·보스 → 정산·상점 → 쓰러지면 끝)는 유지한다.

## 3. 스킬 점수제 \[가설\]

**효과 점수.** 1점은 1챕터 기준 적에게 주는 피해 1이다.

| 효과 | 점수 |
| --- | --- |
| 단일 피해 1 | 1 |
| 광역 피해 1 | 약 2 (대상 수 기대값 × 후열 감소) |
| 지속 피해 | 총량 × 0.8 |
| 붕괴 +10 | 1.5 |
| 약화·취약 (2T) | 각 3 |
| 회복 1 / 보호막 1 | 1 / 0.8 |
| 조건부 효과 | 충족 확률을 곱한다 |

**스킬 값.** 한 번 쓸 때의 순값과 전투당 쓰는 횟수로 잰다.

- 순값 = 효과 점수 − 기준 행동 값 × 행동 시간. 기준 행동은 기본 공격(무기 피해 8 + 붕괴 10 ≈ 9.5점)이다. 스킬은 그 차례에 기본 공격을 포기한 값보다 커야 한다.
- 전투당 횟수 = 시작 충전 + 전투 동안 조건으로 차는 기대 횟수(자동 테스터 기록으로 조건마다 잰다).
- 스킬 값 = 순값 × 전투당 횟수. 대가(생명력 지불, 조건이 까다로움)는 예산을 더 준다.
- 등급별 예산(기본, 중급, 상급, 궁극)에 ±10% 안으로 맞춘다. 자주 차는 스킬은 한 번이 약하고, 드물게 차는 스킬은 한 번이 세다.
- 도구: `tools/skillscore.js`(10월 2일, v0). 스킬 데이터에서 점수표와 화면 설명 문장을 함께 만든다. 장비 효과와 적 능력도 같은 저울에 올린다.
- 기준값(10월 3일 v1, 06a2 실측으로 고침)과 암살자 30개, 시범 측정은 docs/0.6a.2-암살자-스킬.md. 등급별 예산은 v1에서 기본 34, 중급 40, 상급 50, 궁극 70이다(감도 시험에서 목표 완주에 닿은 수치의 중앙값).
- **충전 규칙(초안에서 드러남):** 스킬은 자기 효과로 일어나는 조건으로 충전되지 않는다(흘리기를 하는 스킬이 흘리기 성공으로 다시 차는 고리 금지). 상태를 여러 번 거는 스킬의 걸기 충전은 "3번마다" 이상으로 둔다.

**갈래를 짤 때의 규칙**

- 첫 갈래는 직업의 핵심 키워드, 둘째는 충전·방어 방식, 셋째는 다른 각도의 키워드나 동사를 축으로 삼는다.
- 정해 둔 키워드, 동사, 충전 조건 안에서만 짠다(새 부품을 더하지 않는다).

## 5. 상태 키워드

**지금의 문제 (06a2 = 0.6a 기준):** 상태가 16종이고 그 가운데 7종(덫, 균열, 메아리, 역병, 단죄, 피의 연결, 낙인)은 스킬이나 보스 하나만 쓴다. 쌓이는 규칙이 넷(줄어드는 수치, 한없이 쌓였다 한꺼번에 사라짐, 시간만, 정해진 때 터짐)이고, 숨은 규칙(반대 상태가 통째로 지워짐, 광역은 절반, 플라스크마다 지우는 상태가 다름)이 화면에 보이지 않는다. 스킬 설명에 "내 차례 약 N번"이 13번 나오는데 속도에 따라 실제와 다르다. 지속 피해 넷(출혈, 점화, 역병, 중독)은 숫자만 조금 다르다.

**원칙 (10월 2일 결정)**

1. 모든 상태는 숫자 하나다. 정해진 때가 오면 효과가 나고 숫자가 1 줄어든다.
2. 키워드마다 상한을 따로 둔다. 트리와 유물이 상한을 바꿀 수 있다.
3. 키워드마다 발동하는 때가 달라 서로 다른 판단을 만든다.
4. 숨은 규칙은 없다. 반대 상태는 숫자끼리 뺀다. 설명에는 실제로 걸리는 숫자를 쓴다(광역으로 거는 절반도 줄인 숫자로).
5. 플레이어와 적이 같은 규칙을 쓴다. 보스 전용 표식은 키워드가 아니라 기믹 칸에 둔다.
6. 새 키워드는 기존 키워드로 만들 수 없는 판단이 생길 때만 넣는다(기획서 4.4절 도입 원칙).

**키워드 11개 (외울 개념 8개)**

| 무리 | 키워드 | 언제 발동 | 효과 | 상한 \[가설\] |
| --- | --- | --- | --- | --- |
| 지속 피해 | 중독 N | 시간(1T)마다 | N 피해 | 20 |
| 지속 피해 | 출혈 N | 걸린 쪽이 행동할 때마다 | N 피해 | 10 |
| 지속 피해 | 화상 N | 걸린 쪽이 직접 피해를 받을 때마다 | N 피해 더 | 10 |
| 거울 쌍 | 약화 N ↔ 강화 N | 공격할 때마다(광역도 한 번) | 그 공격의 피해 −25% / +25% | 5 |
| 거울 쌍 | 취약 N ↔ 보호 N | 직접 피해를 받을 때마다 | 그 피해 +25% / −25% | 5 |
| 거울 쌍 | 둔화 N ↔ 가속 N | 행동할 때마다 | 그 행동 시간 +50% / −33% | 3 |
| 막 | 보호막 N | 피해를 받을 때 | N까지 먼저 받아냄(받아낸 만큼 줄어듦) | 최대 생명력의 30% |
| 게이지 | 붕괴 | 붕괴 게이지가 찰 때 | 다음 행동 1회를 잃고 취약 2 | — |

- 발동하면 숫자가 1 줄어든다(보호막은 받아낸 만큼, 붕괴는 게이지 규칙). 반대 쌍은 걸 때 숫자끼리 뺀다(보호 2에 취약 3 → 보호 0, 취약 1).
- 상한을 넘겨 걸면 넘친 몫은 버린다(10월 2일 결정).
- **상한을 넘는 효과는 드물게 둔다(10월 2일 만든 사람 결정).** 상한 올리기, 상한 무시, "넘친 출혈은 즉시 피해" 같은 넘침 효과는 유물, 스킬 트리 후반부(키스톤 깊이), 아주 낮은 확률로 얻는 곳에만 둔다. 트리 앞쪽, 평범·고급 장비, 흔한 보상에는 넣지 않는다. 점수제에서는 상한을 넘는 몫을 가장 높은 등급 예산으로 셈한다.
- **해로운 상태를 다루는 길은 셋이다.** 저절로 줄어듦(발동마다 1), 정화 플라스크(막기만), 정화를 맡은 직업(여러 상태를 지우고 덤까지 얻음: 지운 만큼 보호막, 회복, 적에게 옮기기, 스킬 충전). 플라스크는 막고 직업은 지운다는 구분을 지킨다.
- **전제:** 적의 예고에 걸 상태와 숫자를 보인다(예: "연사 3 × 2, 출혈 3을 건다"). 그래야 정화 플라스크를 미리 마시는 판단이 생긴다.
- 출혈은 방어, 흘리기, 플라스크 같은 빠른 행동을 포함해 모든 행동에 발동한다(10월 2일 결정).
- 지속 피해의 직접 피해 여부: 중독·출혈·화상의 피해는 화상·취약·보호를 발동시키지 않는다(고리를 막는다).
- 시간 대신 횟수로 센다. "다음 공격 3번"은 정확하지만, 빠른 적은 약화를 빨리 써 버린다. 기획서 4.1절의 시계 배정 표를 이에 맞춰 고친다. 중독만 시계에 묶여 "버티기 대 몰아치기" 판단을 남긴다.
- 지금의 표식 7종은 없애거나 위 키워드의 조합으로 바꾼다.

**직업이 키워드를 다루는 동사 (스킬 트리의 재료)**

| 동사 | 예 |
| --- | --- |
| 걸기 | 출혈 3 |
| 키우기 | 대상의 중독 두 배 |
| 터뜨리기 | 남은 총량을 지금 피해로(중독 N이면 N + (N−1) + … + 1) |
| 옮기기 | 내 약화를 적에게 |
| 퍼뜨리기 | 쓰러질 때 남은 출혈을 주변 적에게 |
| 먹기 | 대상의 출혈을 없애고 그만큼 회복 |
| 이용하기 | 취약한 적에게 붕괴 +20 |
| 지우기 | 내 해로운 상태를 −2 |

- 직업마다 키워드 1~2개와 동사 2~3개를 맡는다. 키워드 8개 × 동사 8개 = 64조합이 30종 스킬의 재료다.
- 점수: 키워드 N의 값 = 기대 발동 횟수 × 발동 한 번의 효과. 상한이 기대값을 자른다.

## 8. 적 점수제 \[가설\]

- **위협 점수** = √(버티는 힘 × 차례당 피해) × 속도 × (1 + 능력 점수 합). 능력(치유, 소환, 방패벽, 강타 예고, 상태 걸기 등)은 점수표로 값을 매긴다.
- **방 예산:** 층마다 예산을 둔다(예: 1층 30점 → 하층 70점). 생성기가 예산 안에서 역할 2종 이상을 섞어 방을 짠다. 정예와 강적은 예산 배수로 다룬다. 동시에 충전하는 적 기술은 2개까지(기획서 4.6절 원칙 유지).
- **플레이어 힘 점수:** 레벨, 장비, 트리, 유물로 계산한다. 방 예산과 비교해 챕터 목표(자동 테스터 6성향 평균 20%, 신중 40%)를 숫자로 설계한다.
