# 문구·효과음·능력치 성장 개선 (0.7.0-5)

10월 11일 사용자 요청을 반영했다. 능력치 포인트를 3점으로 바꾸고, 스킬 포인트는 레벨업마다 1점을 유지한다. 스킬 포인트 3점으로 이해했던 중간 변경은 배포 전에 되돌렸다.

## 능력치 성장 [적용]

처음 15점은 유지하고 레벨업 지급량만 2점에서 3점으로 늘렸다. 스킬을 배우는 비용과 장착 4칸, 등급별 챕터 제한은 그대로다.

| 레벨 | 이전 능력치 누적 | 현재 능력치 누적 | 기존 캐릭터 추가 지급 |
| --- | --- | --- | --- |
| 1 | 15 | 15 | 0 |
| 5 | 23 | 27 | 4 |
| 10 | 33 | 42 | 9 |
| 15 | 43 | 57 | 14 |

표는 이벤트 보너스를 제외한 지급량이다. 기존 캐릭터의 배분은 바꾸지 않고 레벨 − 1점을 남은 포인트에 더한다. 지급 기준을 저장하여 다시 이어 해도 중복으로 지급하지 않는다. 전투 중 복원된 캐릭터는 전투가 끝난 뒤, 방 사이의 캐릭터는 다음 전투 진입 전에 배분한다. 미배분 점수와 지급 기준은 판 기록에도 함께 보존한다. 표식 도전은 시작 레벨에 맞춰 능력치 3점씩, 스킬 1점씩 받는다.

## 플레이 문구 [적용]

공개 직업 여섯의 소개를 전투 역할과 별도 분위기 문장으로 나눴다. 직업·갈래 소개, 도움말, 스킬 장착 안내, 능력치 배분 안내를 다듬었다. 목걸이 기본 수치와 장비 정리 안내를 현행 장비 시스템에 맞췄다. 모든 세계관 글과 장비 577종의 문장을 새로 쓴 작업은 아니다.

마검사 갈래는 피칼날 → 혈인, 불칼 → 염검, 주문갑 → 마갑으로 바꿨다. 기존 갈래별 투자 포인트를 이전하고 배운 스킬과 장착은 유지한다. 스킬 이름 67개를 다듬었다. 스킬 id·효과·쿨타임·사거리·등급·부모 연결은 변경하지 않았다.

| 이전 이름 | 현재 이름 |
| --- | --- |
| 막 실은 탄 | 마갑탄 |
| 껍질 주문 | 마갑 전개 |
| 막 터뜨리기 | 방벽 해방 |
| 피 새겨 베기 | 혈각참 |
| 칼에 불 싣기 | 염화 부여 |
| 기 실은 주먹 | 기공권 |

## 효과음 [적용·청취 확인 필요]

공격·스킬·방어 음원 17개를 기존 사용자 제공 음원 중심으로 재편집했다. 검과 화살은 큰 피해를 줘도 둔기 강타음으로 바뀌지 않는다. 상태 부여와 속성 없는 지속 피해의 반복 알림음을 제거했다. 파일별 출처·변환과 음량은 `docs/조사/효과음-출처.md`의 0.7.0-5 절에 기록했다.

브라우저에서 음원 31개를 디코딩하고 최대 음량·길이를 확인했다. 자동 검증은 음색의 어울림을 판단하지 않는다. 이번 재편집의 청취감과 능력치 증가 후 장기 밸런스는 사용자 플레이로 확인해야 한다.

## 검증

- `tools/player-growth-check.js`: 스킬 포인트 유지 135조건, 기존 능력치 보충 15레벨, 중복 지급 방지, 갈래 투자량 이전, 초기화, 여러 레벨업과 표식 시작, 이름 이외 스킬 전투 데이터 유지.
- `tools/player-text-browser.py`: 가짜 저장소로 직업·세 갈래 화면을 390px·1280px에서 확인. 초기 능력치 15점, 기존 부족분과 미배분 6점의 배분·저장·전투 진입, 음원 31개 디코딩. 실제 이용자 기록은 사용하지 않는다.
- `tools/helpcheck.js`: 숫자 문장 1551개를 모두 대조. 통합판 출시 당시의 능력치 2점 문장은 이력으로 분리하고 현행 지급량을 따로 검증한다.
- `tools/classaudit.js`와 `tools/docsync.js --check`: 현행 직업 표와 코드 일치.
- `tools/textnum.js`: 스킬·직업 데이터의 설명 숫자는 이전과 동일. 도움말 숫자 변경은 능력치 2→3과 스킬 트리의 예시 레벨을 줄별 안내로 교체한 데 따른 것이다.
- 기존 효과음 재생·장비 성장 회귀 통과. 3챕터 장비 240항목, 3챕터 규칙 41항목 통과.

공개판 사본의 경로·음원·설정·화면 편집·전투 흐름 리허설도 모두 통과했다.
