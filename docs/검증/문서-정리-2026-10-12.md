# 문서 구조·개선 기록 정리 — 2026-10-12

## 정리한 구조

- 루트의 핵심 문서 6개와 분야별 폴더 구조를 유지했다. 과거 기록·화면·JSON 증거를 일괄 이동하거나 삭제하지 않았다.
- [문서 안내](../문서-안내.md)에 읽는 순서, 최근 규칙, 적용·제안·과거 이력의 구분을 추가했다.
- [0.7.0 개선 현황](0.7.0-개선-현황.md)에 성장·장비·가방·설명·보스 정보·가혹 진행·다중 세이브·계정 연동·도감·타이틀·접근성·자동 갱신의 근거를 묶었다.
- [통합 기획서](../현행-통합-기획서.md)와 [완료 점검](../완료-점검.md)을 최신 상태로 정리했다. 이전 완주율·합격 표는 측정 이력으로 남겼다.
- [만든사람 결정](../만든사람-결정.md)에 최근 승인·구현·미적용 분석을 분리해 기록했다. 이미 답한 과거 질문을 새 승인 요청으로 읽지 않도록 표시했다.
- [이전 스킬 성장 기록](스킬성장-마검사-완주빌드.md)에 교체된 공식과 보호막 소모 규칙의 현행 문서를 연결했다. 과거 검사 결과의 수치는 고치지 않았다.
- 마검사 문서의 자동 코드 기준 블록을 현행 갈래·시작 스킬 이름으로 갱신했다. 통합 기획서의 옛 갈래명과 잠긴 직업 표시도 현행에 맞췄다.
- 자동 설명 대조표의 배열 예시가 링크로 해석되던 표기를 코드 표기로 고쳤다. 생성 도구도 같이 맞췄으며 검사 판정·숫자는 유지했다.

## 상세 원문과 공개 요약

프로젝트의 [공개 범위 기준](공개문서-비공개-점검.md)에 따라 보스 조건·해금 직업 상세가 포함된 제안서 2개를 저장소 밖 `nrk-private/제안/`에 보존했다. `docs/제안/`에는 공개 요약과 [목록](../제안/README.md)을 남겼다.

보고서 생성 도구의 출력도 비공개 경로로 바꿨다. 다시 생성해도 공개 요약을 덮어쓰지 않는다. 운영 기능은 `nrk-private/운영/`에 별도 문서로 정리했다. 공개 플레이어 업데이트 내역은 변경하지 않았다.

## 검증

- `node tools/docs-links-check.js`: 공개 문서의 로컬 Markdown 파일 링크 검사. 코드 예시의 링크 모양 문자열은 제외하고 웹 URL·절 제목 앵커는 검사하지 않는다.
- 같은 도구로 새 비공개 안내·제안·운영 문서의 상대 링크도 확인한다.
- 공개 문서와 새 비공개 문서 합계 80개, 로컬 파일 링크 110개를 검사해 누락 0개를 확인했다. 웹 URL·앵커와 기존 비공개 문서 전체의 재감사는 이번 범위에서 제외했다.
- `node tools/docsync.js --check`: 공개 6직업·비공개 3직업의 자동 코드 기준 블록 일치 확인.
- 보고서 생성기를 재실행해 원문이 비공개 경로에 생성되고 공개 요약이 보존되는지 확인한다. 비교 표본 16,704회·39,888회와 원자료는 유지한다.
- `node tools/admin-details-check.js`: 루트·06a2의 장비·트리 스냅샷·과거 기록·동명이인 구분·직업 렌더 검사가 통과했다. 이번에는 브라우저·실서버 운영 검사를 재실행하지 않았다.

문서 정리 단계에서는 게임 수치·세이브·서버 데이터·권한을 바꾸지 않았다. 이후 가속 소모·비율 보호막 채우기·실제 피해 자원 계산은 [별도 변경](전투자원-계산-수정-2026-10-12.md)으로 수정·검증·배포했다. 주 능력치 연결·추천 후보는 미적용이며 실제 제보 계정의 PC→모바일 성공도 여전히 확인 필요다.
