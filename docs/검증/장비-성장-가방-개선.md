# 장비 성장과 가방 개선 (0.7.0-4)

## 요청과 근거

만든 사람은 챕터·등급에 따른 피해와 생존력의 성장 차이, 특수 효과 유지, 목걸이 개선을 요청했습니다. 불편한 흐름은 소모품 찾기·사용, 장비 비교·교체, 획득 후 정리라고 확인했습니다.

기존 기준은 `아이템/장비-경제.md`의 장비 효과 개성·필수 장비 금지·전설 제한과 `조사/UI-근거.md`의 실제 계산 비교·가방 획득 흐름입니다. 이번 수치는 성장 체감을 위한 조정 가설입니다. 사람의 플레이로 균형이 확정된 수치가 아닙니다.

## 기본 수치

등급 보너스와 특수 효과를 더하기 전 값입니다.

| 장비 | 이전 1·2·3챕터 | 변경 1·2·3챕터 |
| --- | --- | --- |
| 무기 피해 | 8·11·15 | 8·13·20 |
| 갑옷 최대 생명력 | 10·16·24 | 10·20·34 |
| 장갑 최대 스태미나 | 5·8·12 | 5·9·14 |
| 목걸이 | 최대 마나 5·8·12 | 최대 스태미나 5·9·14 |
| 반지 최대 생명력 | 5·8·12 | 5·10·17 |
| 플라스크 회복 비율 | 30·30·30% | 30·32·34% |

새로 얻는 장비의 기본 수치 보너스는 평범 1~5%, 고급 8~14%, 희귀 18~26%, 영웅 30~40%, 전설 45~55%입니다. 보유 장비의 보너스 값은 다시 굴리지 않습니다. 보유한 장비도 챕터 기본 수치와 목걸이 변경은 적용됩니다. 이어하기와 전투 복원에서 남은 자원 비율을 유지하며 장비 수치를 다시 계산합니다. 기존 장비 설명에는 보유 보너스를 표시해 새 생성 범위 안에서 얻은 것으로 오해하지 않도록 했습니다.

특수 효과·대가, 드롭 확률, 직업 제한, 전설 한 개 제한, 이전 챕터 드롭 규칙과 상점 가격은 변경하지 않았습니다. 상위 챕터·등급만으로 특수 효과를 무조건 버리는 자동 추천은 추가하지 않았습니다.

## 가방 흐름

- 소모품: 전체·회복과 해제·전투·탐색과 판매 분류, 이름과 효과 검색, 지금 사용 가능 필터. 사용 가능한 것을 먼저 표시하며 원래 소모품 인덱스로 사용합니다. 사용 후에도 검색·분류를 유지합니다.
- 적 대상 소모품: 창에서 적을 고르고 각 소모품의 실제 적용 대상을 보여 줍니다. 선택한 적에 적용할 수 없으면 기존 대상 규칙으로 고른 실제 대상이 표시됩니다.
- 소모품 정리: 전투 밖에서 묶음 전체를 버릴 수 있으며 이름·개수를 확인합니다. 전투 중 정리는 제한합니다.
- 장비: 칸을 선택하면 맞는 장비를 거릅니다. 전체 보기, 등급순·최근 획득순 전환, 가방 카드의 챕터·기본 수치를 추가했습니다. 실제 획득 시각이 없는 옛 장비는 기존 가방 순서를 보조 기준으로 씁니다.
- 비교·교체: 효과·대가와 실제 엔진 수치 비교를 유지합니다. 반지 비교 칸을 유지하고 교체 뒤 가방 목록으로 이동합니다.
- 획득: 마지막 전리품 창에서 가방에 두고 바로 정리할 수 있습니다. 여러 전리품이 남았을 때는 기존 획득 흐름을 먼저 마칩니다.
- 한도: 장비 해제 버튼도 소모품 겹을 포함한 실제 가방 사용량으로 제한합니다.
