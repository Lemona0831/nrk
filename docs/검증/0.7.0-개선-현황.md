# 0.7.0 개선 현황 — 2026-10-12

> **10월 13일 가방 수정:** 등급 누락 저장본의 소모품 묶음 채우기와 상점 공간 표시를 바로잡았다. 현재 용량은 묶음당 한 칸이며 별도 무게 페널티는 없다. [원인·검증](소모품-묶음구매-가방공간-2026-10-13.md).

> **10월 13일 추가 적용:** 사냥꾼 추적 소모 추가 피해에 민첩 2%/점 성장, 암살자 독 격발의 기존 지능 보정 표시를 반영했다. [비교·구현·화면 검증](독격발-추적-성장검증-2026-10-13.md). 연속 던전 후반 진입 근거를 추가했으나 9직업 전체 균형은 계속 검토 중이다.

최근 적용한 변경과 검증 근거를 분야별로 찾는 색인이다. 게임 규칙은 [현행 통합 기획서](../현행-통합-기획서.md), 적용 전 후보는 [제안 목록](../제안/README.md)을 따른다. 과거 검사에 통과한 기록을 현재 전체 밸런스의 합격으로 해석하지 않는다.

## 상태를 읽는 법

- **적용:** 현재 코드에 들어간 기능·규칙이다. 플레이 체감과 실제 계정 성공까지 확인했다는 뜻은 아니다.
- **조정 중:** 현재 코드는 적용돼 있지만 밸런스를 계속 평가한다.
- **제안:** 격리 실험·분석 단계이며 게임 수치에 반영하지 않았다.
- **확인 필요:** 실제 계정·기기·연속 던전 등 아직 증거가 없는 범위다.

이 전투 표본은 전투마다 정해진 장비·생명력·플라스크 조건을 사용하는 진단이다. 실제 연속 던전 완주율, 실제 플레이어 승률, 최신 장비 조합의 균형으로 합산하지 않는다.

후속 실제 행동 역할 대응은 34,992조건을 짝지어 변경 전·후 전투69,984회를 비교했다. 개인 분석은 모든 기록된 행동을 확인했지만 합성 시험의 고유 행동 선택 시도 범위는2,749/2,832이며 전투 간 자원은 재생하지 않았다. [계산 수정·검증 범위](전투자원-계산-수정-2026-10-12.md)를 따른다.

추가 [연속 던전 행동 정책](연속-던전-행동정책-2026-10-12.md)은 실제 Lv1·20점에서 방 사이 자원을 유지해 현재판/성장 후보1,944판을 비교했다. 일부1챕터 통과는 있었으나2챕터를 통과하지 못해 후반 판단은 미검증이다. 기본 공격 성장 연결·마검사 추가 너프·던전 피해 일괄 상향은 적용하지 않았다. QA의 장비별 플라스크 한도 검사는 수정했다.
