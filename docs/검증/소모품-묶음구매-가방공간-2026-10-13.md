# 소모품 묶음 구매·가방 공간 — 2026-10-13

## 원인과 적용

현재 가방은 무게가 아니라 칸 수로 제한한다. 장비 하나는 한 칸, 소모품은 같은 종류·등급의 한 묶음이 한 칸이다. 약초 상한은 묶음당 5개이므로 약초 25개·5묶음은 5칸을 사용한다. 이번 수정에서 무게 페널티나 보유 개수 제한을 새로 추가하지 않았다.

현재 일반 등급 저장본은 마지막 칸의 약초 1개에 4개를 더 구매할 수 있었다. 등급 정보가 누락된 저장본에서는 표시상 일반인데 같은 묶음으로 인식하지 못해 구매가 막혔다. 이 조건을 재현해 수정했다. 제보자의 실제 저장본 등급은 미확인이다. 고급과 일반을 합치는 것은 효과 수치가 다르므로 허용하지 않는다.

- 등급 누락은 일반으로 해석하고 기존 묶음부터 채운다. 드롭 보상·보류 보상 선택에도 같은 공간 판정을 사용한다.
- 상점의 구매 가능 표시와 실제 구매가 같은 공간 판정을 사용한다. 실패 구매는 골드·소모품·구매 로그를 바꾸지 않는다.
- 상점에 개수·사용 칸·상한·일반 묶음의 남은 자리를 표시한다. 하단 사용량에서도 소모품 칸을 센다.
- 기존 즐겨찾기·획득 표시·등급별 효과를 보존한다.

## 검증

공개판·개발판 각각 소모품 53종·447조건 통과. 마지막 칸의 1→5개 채우기, 등급 누락 저장본, 일반/고급 분리, 새 묶음 생성, 골드 부족·공간 부족 시 변경 금지, JSON 저장 후 재구매, 사용 후 빈 자리, 보류 보상 채우기를 검사했다. tools/cons-stack-space-check.js로 재현한다.

로컬 실제 브라우저 1280px·390px에서 일반/등급 누락의 4조건을 구매 버튼으로 확인했다. 약초 네 번 구매 후 5개·가방20칸·골드48 차감·구매 로그4건, 이후 공간 부족 표시와 가로 넘침 없음을 확인했다. 계정 저장은 끈 로컬 시험이며 실제 제보 계정의 재구매 성공은 별도 확인이 필요하다.
