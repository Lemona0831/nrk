# 초기 성장·직업 설명·접근성·로그인 검증

적용 판: 0.7.0-7 / 2026-10-11

초기 스탯 포인트를 15에서 20으로 늘렸습니다. 기존 캐릭터에는 부족한 5포인트를 한 번만 지급하며, 이미 배분한 능력치는 유지합니다. 레벨당 스탯 포인트는 3, 스킬 포인트는 1입니다.

모든 직업의 핵심 규칙을 짧게 표시하고, 계산식은 별도 줄로 구분했습니다. 조건과 예외는 펼쳐서 읽습니다. 원소술사의 열기 상한 16도 실제 계산과 일치하도록 명시했습니다. 시작 스킬 중 각 직업의 대표 스킬 두 개는 재사용 시간을 줄였으며, 시작 스킬의 재사용 시간은 4~6턴입니다. 상세 직업 효과는 게임 안의 설명에서 확인합니다.

설정에 선택 위치 강조, 전투 화면 스크롤, 자동 설명 끄기, 길게 누르기 시간 조절을 추가했습니다. 키보드 설명 열기와 닫기, 터치 시간 조절, 설정 저장과 다시 접속 후 복원을 확인했습니다.

첫 화면에 구글 로그인 버튼과 플레이어 이름 설정을 제공합니다. 계정을 바꾸거나 로그아웃하면 기기 기록을 계정별로 보관하고, 다시 로그인할 때 해당 계정의 기록을 복원합니다. 손님 기록을 계정에 연결할 수 없는 서버에서도 일반 로그인과 기록 파일 다운로드를 제공합니다. 실제 구글 인증 화면으로 향하는 응답을 확인했으며, 로그인 완료·로그아웃·계정 복원은 가짜 계정으로 검증했습니다. 실제 사용자 계정의 인증 완료는 이번 자동 검증에 포함하지 않았습니다.

같은 12개 시드로 9개 직업을 신중한 행동 성향 하나에서 비교한 108회 표본에서 1챕터 돌파는 16회에서 28회로 늘었습니다. 최종 연속 진행 표본은 2챕터 10회, 3챕터 5회 돌파했으며 실행 오류는 없었습니다. 작은 표본이므로 모든 직업의 승률 상승을 의미하지 않습니다.

검증 결과: 설명과 계산식 대조 1,575건 통과, 기존 저장 사례 56건 통과, 3챕터 검증 41건 통과, 장비 검증 10,386건과 7,020건 통과, 장비 흐름 검증 5,193건 통과, 기존 성장 이관 사례 135건 통과. 초기 성장과 회복 동작, 전체 시작 스킬, 모바일·데스크톱 설명, 로그인·계정 분리, 접근성 설정을 추가로 검증했습니다. 실제 서버의 사용자 기록에는 쓰지 않았습니다.
