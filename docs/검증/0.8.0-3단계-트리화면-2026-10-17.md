## 2. 그림 [사실]

**판:** 돌판(어두운 원) 위에 놋쇠 테 두 줄과 그 사이의 룬 고리, 방향 사이의 점선 나눔, 고리 경계 원(눈금 있는 두 줄). 색은 게임의 `--gold` · `--line` · `--ink` · `--muted`를 쓰고, 놋쇠 · 길 덤(청록) 같은 몇 가지만 `--tr-*`로 더했다. 바깥 그림 · 글꼴은 쓰지 않는다(문양은 SVG 선).

**패시브:** 설계 2-1 그대로. 각도 = 방향(화력 0° 시계 방향 60°씩) + 칸(L −12° · C 0 · R +12°), 반지름 = r × 46. 고리 경계는 r 3.5 · 6.5. 다리(R3 → 이웃 L3, R6 → 이웃 L6)는 같은 반지름의 호로 그린다. 방향 이름은 바깥(기울기 가까움 · 보통 · 멂과 함께)과 두 고리 경계 위에 한 번 더 적어, 확대해도 축 이름이 보인다. 고리 번호는 방향 사이(30°)에 적는다.

**액티브:** 마검사는 데이터의 갈래 각도(마갑 0° · 염검 120° · 혈인 240°)와 칸 각도(±18° · ±36°), 반지름 = r × 80. 임시 트리(8직업)는 갈래를 0 · 120 · 240°, 칸을 ±13°, 줄을 반지름(40 + 줄 × 44)으로 놓는다. 고리 경계는 고리마다 스킬 노드 반지름의 사이. 갈래 이름은 바깥과 시작 노드 바로 바깥에 적는다.

**노드 모양:**

| 노드 | 모양 |
| --- | --- |
| 작은 노드 | 작은 원 |
| 중간 노드 | 큰 원 + 방향 문양(화력 칼 · 제어 망치 · 기민 겹 갈매기 · 계승 잔 · 유지력 물방울 · 생존 방패) |
| 큰 각인 | 마름모 + 방향 문양 |
| 시작 | 금빛 메달 "시작" |
| 액티브 스킬 | 큰 원, 안에 ⚔(베기) · ✦(주문) 문양과 유산 비용. 장착한 스킬은 굵은 금빛 테를 하나 더 두른다 |
| 액티브 강화 | 그 스킬 곁에 붙은 작은 위성(짧은 선으로 이음, 안에 ^ 표) |

강화 위성 자리는 계산한다: 스킬 둘레 10° 간격 후보 가운데, 데이터 자리 쪽(왼 · 오른 칸, 바깥)에 가깝고, 스킬끼리의 이음선 · 같은 스킬의 다른 위성 · 다른 노드와 겹치지 않는 곳. [판단] 데이터의 강화 자리(`pos`)는 스킬에서 멀리 떨어진 것이 있어(예: 끓는 피 r3, 혈염 r2) 그대로 두면 어느 스킬의 강화인지 보이지 않는다.

**상태(그림 읽는 법):**

| 상태 | 패시브 | 액티브 |
| --- | --- | --- |
| 찍음 / 열림 | 금빛으로 채움, 이음선이 밝은 금빛 | 같음 |
| 길 덤 | 청록 점선 테 + 오른쪽 위 청록 점, 이음선 청록 점선 | 없음 |
| 얻은 큰 각인 | 금빛 마름모, 빛남 | 없음 |
| 찍을 수 있음 | 밝은 테 + 은은히 숨쉬는 바깥 테, 열린 노드에서 오는 선이 금빛 점선 | 같음 |
| 이웃이 열렸지만 포인트가 없음 | 점선 테 | 같음 |
| 잠김 | 어두운 테 | 같음 |
| 고리 잠김 | 노드가 흐려지고(점선 테), 고리 띠에 빗금, 고리 번호 아래 "잠김 · 2챕터부터 / 3챕터부터" | 같음 |
| 장착 | | 굵은 금빛 바깥 테 |
| 연 강화가 일하지 않음 | | 어두운 금빛 점선 위성(그 스킬을 끼우면 일함) |
| 큰 각인 후보 | 빛나는 마름모 + 번호(1 · 2 · 3) + 이름이 늘 보임, 덤으로 열릴 길(청록 점선, 고른 후보는 굵게)과 그 길의 노드(청록 점선 테) | |

고른 노드는 노란 테로 두른다. 그림 아래 "그림 읽는 법"(PC는 펼침, 휴대폰은 접힘)에 같은 표시가 있다.

**이름:** 배율이 커질수록 더 보인다. 큰 각인 · 중간 노드 이름은 화면 배율 0.78 이상, 작은 노드 값(힘 +2 등)은 1.9 이상, 액티브 스킬 이름은 0.5 이상(임시 트리 0.95), 강화 이름은 1.9 이상. 고른 노드와 큰 각인 후보는 늘 보인다.

## 3. 다루기 [사실]

| | PC | 휴대폰 |
| --- | --- | --- |
| 확대 | 휠(커서 자리 기준), ＋ · － 단추, 노드에 초점이 있을 때 + · − 키 | 두 손가락, ＋ · － 단추 |
| 이동 | 끌기 | 한 손가락 끌기 |
| 전체 보기 | "전체" 단추 | 같음 |
| 노드 설명 | 누르면 오른쪽 칸(이름 · 종류 · 방향 · 고리 · 비용 · 효과 · 대가 · 상태 · 못 찍는 까닭 · 단추) | 누르면 지도 아래쪽에 겹친 설명 칸(높이 절반 이하, ✕로 닫음, 단추 줄은 칸 아래에 붙음). 고른 노드가 그 뒤에 가리면 위로 옮겨 보인다 |
| 닫기 | ✕, 빈 곳 누르기, Esc | ✕, 빈 곳 누르기 |
| 키보드 | Tab으로 그림에 들어가면(노드 하나만 Tab 자리) 화살표로 그 방향의 가장 가까운 노드로 옮기고 설명이 따라온다. Enter · Space: 설명을 열고, 이미 연 노드면 찍기(열기). Home: 시작 노드. Esc: 설명 닫기(초점은 노드에 남는다). 초점 테가 보인다 | |

- 확대 · 이동은 이번 접속 동안 트리마다(패시브 · 액티브 · 큰 각인 고르기, 직업별) 기억한다. 처음 볼 때는 열린 고리까지(한 칸 더) 맞춰 크게 보이고, 큰 각인 고르기는 후보까지 맞춘다. "전체"는 판 전체.
- 끈 뒤의 누르기는 노드를 고르지 않는다(6px 넘게 움직이면 끌기).
- 능력치 합계(패시브): PC는 설명 칸 아래, 휴대폰은 그림 아래 접는 칸 "능력치 합계". 힘 · 민첩 · 지능 · 체력 · 의지마다 합과 출처(시작 · 노드 · 길 덤), 작은 노드 효과(제어 붕괴 · 계승 스태미나).
- 포인트와 탭: "패시브 · n점 / 액티브 · n점" 그대로, 그 옆에 "목록으로 보기"(눌린 상태 표시, 이 기기에 기억 `G.data.treeList`). 목록형은 2단계 화면 그대로다.
- 큰 각인 고르기: 그림 위에 후보 셋(번호 · 이름 · 길), 아래에 카드 셋. 카드의 "그림에서 보기 · 후보 n"은 그 후보를 그림에서 고르고 보이게 옮긴다. 고르기는 카드의 "이것을 고른다" 또는 그림 설명 칸의 같은 단추. PC는 첫 후보를 먼저 골라 둔다.
- 움직임: 찍을 수 있는 노드의 바깥 테가 천천히 숨쉬고, 방금 찍은 노드는 잠깐 빛나며 새 이음선이 0.5초 동안 그려진다. 설정의 "움직임 줄이기"나 브라우저의 움직임 줄이기면 모두 끈다.

## 6. 알려진 것

1. PC에서 휠은 그림 위에서 확대로만 쓰인다(페이지가 스크롤되지 않는다). 휴대폰은 그림 위를 끌면 그림이 움직이므로 페이지는 그림 밖을 끌어 스크롤한다(그림 높이는 화면의 60% 안팎).
2. 배율이 낮으면 이름 대부분이 숨는다(겹치지 않게). 중간 배율에서는 이름이 이음선이나 다른 이름과 조금 겹치는 곳이 있다(액티브 시작 노드 곁의 갈래 이름 등).
3. 강화 위성 자리는 계산한 것이라 데이터의 `pos`와 다르다. 스킬보다 바깥 고리인 강화(예: 끓는 피, 혈갈)는 스킬 곁에 있으면서 고리 잠김으로 흐려 보인다.
4. 임시 트리(8직업)의 액티브는 13줄 × 두 칸에 `par` 이음이 엇갈려 X자 모양이 많고 촘촘하다. 직업 트리 내용이 들어오는 5 · 6단계에서 다시 본다.
5. 확대 · 이동은 트리마다 기억하므로, 고리가 새로 열려도 예전 보기로 열린다. "전체"로 판 전체를 본다.
6. 2단계 브라우저 연기 시험 스크립트(목록형 단추를 누름)는 이제 "목록으로 보기"를 켜야 돈다. `.py` 브라우저 도구는 이번에도 돌리지 않았다.
7. 휴대폰 설명 칸이 지도 아래쪽 절반 가까이를 덮는다(✕ · 빈 곳 누르기로 닫음, 고른 노드는 위로 옮겨 보임).
