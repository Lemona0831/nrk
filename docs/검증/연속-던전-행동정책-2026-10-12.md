# 행동 정책의 연속 던전 검증

2026-10-12. 게임 규칙은 `078a5a6` 기준이다. 개인 기록과 상세 결과는 저장소 밖에 보관한다. 이번 작업은 검증 도구·보고서 보완이며 게임 수치나 플레이어 업데이트 내역을 변경하지 않는다.

## 추가한 범위

기존 69,984회 역할 대응 전투는 전투마다 정해진 장비·자원으로 시작했다. 후속 시험은 실제 게임의 Lv1·20점에서 던전을 진행하며 방 사이의 생명력·장비·플라스크·소모품을 유지한다. 실제 획득 포인트만 배분하고 실제 드롭·상점·가방 처리 경로를 사용한다.

주 비교는 9직업 × 9개 관찰 정책 × 일반/가혹 × 원 배분/공격 능력치 대응 배분 × 시드3개다. 현재 규칙과 기본 공격 성장 연결 후보를 각각972판, 합계1,944판 비교했다. 후보는 게임에 적용하지 않았다. 기록의 행동 순서 대신 현재 상태가 가까운 행동을 고르는 대안 정책도162판 검사했다.

원본의 모든 기록을 분석한 범위와 시험에서 실제 실행한 범위를 구분한다. 주 현재판 시험이 시도한 서로 다른 관찰 행동은1,058개다. 일찍 사망하면 이후 행동·장비·초기화를 실행하지 못한다. 과거 코드·씨앗·전체 선택지가 없으므로 실제 과거 판의 재현이나 실제 플레이어 승률이 아니다.

마검사 보호·쿨타임 보상을 줄이는 추가 후보는 격리 전투1,296쌍과 연속 던전20쌍을 비교했다. 격리 표본은 양쪽801승이며 HP·보호막 획득·행동 수의 변화가69쌍에서 관찰됐지만 승패 전환은 없었다. 특정 성공판의 후반 유지력을 검증한 결과가 아니므로 추가 너프를 확정하지 않았다.

현재 결정은 기본 공격 성장 연결 후보·마검사 추가 너프·던전 피해 일괄 상향을 적용하지 않는 것이다. 기존 [계산 수정](전투자원-계산-수정-2026-10-12.md)은 유지한다. 후보의 불확실성을 현재 게임 수치로 덮지 않는다.

## 버프·너프 판단 순서

- 우선 계산·표시 오류와 실제 성능 문제를 분리한다. 설명과 실행이 어긋나는 계산은 재현 조건을 고친다.
- 같은 능력치 예산·합법 장착·장비·보급·시작 상태의 짝 비교에서 공격, 방어, 연계, 자원, 대상 접근, 제어를 각각 기록한다. 공격 투자가 전투 시간을 줄이는 이익과 방어 투자가 실수를 버티는 이익을 같은 승률 하나로 합치지 않는다.
- 특정 반복이 피해·방어·자원 비용을 동시에 해결한다면 해당 보상 원천을 하나씩 줄여 확인한다. 한 완주나 단순 반복 정책의 승리만으로 직업 전체를 낮추지 않는다.
- 충분한 대응 수단을 합법적으로 갖춘 갈래도 여러 조건에서 피해·자원 비용 때문에 진행하지 못한다면 버프 후보로 삼는다. 잘못된 장착·누락 역할·약초 부족·시험 정책 실패가 원인인 경우는 먼저 조건을 수정한다.
- 변경 적용 전후에 일반/가혹·초중후반·공격/방어 배분·보급 유무를 함께 확인한다. 이후 자원이 이어지는 던전 시험이 후반에 도달하지 않았다면 해당 범위는 미검증으로 남긴다.

## 검증 도구 수정

`tools/dgqa.js`에 선택 정책을 받는 선택적 훅을 추가했다. 기록 정책을 쓸 때는 기본 QA의 보스 대응·치유사 대상 변경·도주 강제 취소를 자동으로 섞지 않는다. 훅이 없으면 기존 동작을 유지한다. 변경 전 고정 코드와6개 판을 비교해 결과·자원·장비·행동·난수가 같았다.

QA 플라스크 검사는 기본 최대 충전 대신 종류별 실제 `flaskCap`을 사용한다. 추가 충전 장비의 정상4개를 오류로 잡던 검증기 문제를 고쳤다. 실제 최대 초과·음수·비정수는 계속 실패한다. 게임의 충전 수를 바꾼 것이 아니다.

공개 구조 검사는 `node tools/dgqa-policy-check.js`로 실행한다. 개인 기록 기반 선택 정책과 상세 결과는 공개 CI에 포함하지 않는다. 초기 배분 객체가 후속 성장으로 바뀌던 시험 기록 오류도 사본 보존으로 고치고 전체 주 비교를 다시 실행했다. 원본 파일과 플레이어 세이브는 수정하지 않았다.
