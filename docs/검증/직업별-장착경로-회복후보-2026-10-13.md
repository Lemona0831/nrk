# 직업별 장착 경로·회복 후보 — 2026-10-13

**적용:** 자동 판단 도구의 피해 추정 수정. **보류:** 흡혈 계수 감소 후보. 이번 기록은 게임 전투 계수 변경과 구분한다. 9직업의 전체 균형은 계속 검증 중이다.

## 측정 도구 수정

자동 판단의 일부 피해 추정이 스킬 기준 피해를 그대로 사용해 현행 능력치·무기 성장을 놓쳤다. 보호막 추가 피해의 상한·소모, 기 추가 피해 성장, 독 격발의 지능 보정·부분 소모도 누락됐다. 게임 계산 함수를 판단용 엔진에 내보내고 해당 추정에 연결했다. 기본·강공격도 실제 주 능력치 보너스와 무기 페널티를 반영한다.

`tools/qa-growth-estimate-check.js`는 공개판·개발판 각각 다음을 확인한다.

- 9직업의 스킬 기본 피해 1,758조건: 추가 효과를 제거한 실제 스킬 실행과 비교.
- 보호막 추가 피해 40조건: 상한·소모를 실제 실행과 비교.
- 기본·강공격 108조건, 독 격발 108조건: 실제 행동·부분 독 소모·지능 보정과 비교.
- 자원 계수 5,673조건: 선택 성장과 고정 효과를 게임 함수와 대조. 이 대조만으로 전체 복합 피해를 증명하지 않는다.

판단값은 부작용 없이 계산한다. 전체 장비 효과·적 상태·행동 비용을 모두 정확히 예측하는 최적 플레이어를 구현한 것은 아니다. 최종 판단 도구로 9직업·세 갈래·일반/가혹의 연속 54판을 추가 실행해 합법 행동·전투 불변식을 확인했다. 이전 측정의 숫자는 해당 정책의 이력으로 보존하며 최신 판단 결과로 바꾸어 쓰지 않는다.

## 전용 트리 경로 비교

관찰된 경로·장비·소모품 선택은 유지하고, 대상 직업의 단일 갈래 왼쪽 또는 오른쪽 스킬을 실제 포인트로 해금한다. 장착은 공격 두 칸·방어 한 칸·자원/통제 한 칸을 우선하고 부족하면 열린 칸으로 채운다. 공격·혼합·추천의 시작 20점, 실제 레벨업 포인트, 획득 장비·소모품과 연속 자원을 유지했다.

원래 판단으로 648판, 스킬 기본 피해·선택 자원·보호막·독 배율 추정을 고친 중간 판단으로 648판을 실행했다. 다음 표는 **중간 판단의 직업별 36판씩**이다. 이후 기본·강공격 및 부분 독 소모 판단도 보완했으므로 이 표를 최종 도구의 완주율로 쓰지 않는다. 초기 시드 하나·관찰 프로필 두 개·세 갈래·두 모드이며 최적 빌드나 실제 승률이 아니다. 장착 경로가 바뀌면 행동·난수 소비·획득도 달라진다.

## 회복 조정 후보 보류

두 직업의 실제 스킬 3,840조건에서 같은 20점 예산·고정 자원 상태·처치 가능/불가능 표적의 피해와 회복 원천을 분리했다. 흡혈은 공격 피해에 비례하므로 공격 투자가 회복도 늘리지만, 다른 회복 원천은 같은 관계가 아니다. 복수 타격은 회복된 생명력에 따라 후속 피해 배율도 바뀔 수 있어 피해 불변을 가정하지 않는다.

흡혈 한 원천만 낮춘 후보를 전용 경로·다섯 배분·두 모드·두 관찰 프로필에서 현행과 120쌍 비교했다. 모든 조건에서 실제 획득 장비·소모품과 챕터 간 자원을 유지했다.

| 배분 | 현행 완주 | 후보 완주 |
| --- | ---: | ---: |
| 공격 | 12/24 | 11/24 |
| 혼합 | 8/24 | 7/24 |

완주→실패 11쌍, 실패→완주 5쌍이다. 공격 배분보다 추천 배분의 손실이 컸다. 과도한 공격·유지력 중첩을 줄이면서 낮은 투자·자원 부족의 생존을 보존하려는 기준에 맞지 않아 적용하지 않았다. 로컬 Qwen의 상한 해석 오류도 코드 대조 후 폐기했다. 이 결과로 다른 회복·장비·약초까지 한꺼번에 낮추지 않는다.

원자료·개인 기록 대응·후보 수치와 모델 응답은 저장소 밖 `nrk-private/`에 보존한다. 다음 조정 기준은 **공격·연계·방어·유지력·대상 접근·통제**의 여섯 축이다. 행동 비용·같은 성장 예산·연속 자원은 공통 비교 조건이며 별도의 축으로 바꾸지 않는다. 상향은 실제 전용 운영에서도 약한 원천에 한정하고, 하향은 여러 축을 동시에 해결하는 원천을 분리한 뒤 낮은 투자·다른 갈래의 손실을 함께 확인한다.
