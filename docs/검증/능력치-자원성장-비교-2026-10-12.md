# 능력치 자원 성장·투자 비교 검증

2026-10-12. 변경 전 기준 `fc12dad`. 루트 공개판과 `06a2`에 같은 변경을 적용한다. 배포 상태와 전체 직업 밸런스 완료 여부는 별도로 판단한다.

## 적용한 변경

- 수도승의 기 터뜨리기·기 비례 추가 피해와 해금 2의 선택된 자원 추가 피해에 힘 1점당 기준값의 1% 성장을 연결했다. 힘 0·10·20점에서 해당 추가 피해는 기준값의 100·110·120%다. 스킬 기본 피해의 4% 배율과 분리한다.
- 관련 스킬 설명·전투 버튼·실제 처리에서 같은 계산을 사용한다. 다른 자원 피해, 보호막·회복 한도, 수급·소모, 붕괴, 행동 속도·쿨타임에는 이 성장 배율을 적용하지 않는다.
- 전 직업 능력치 창의 ‘3점 투자 시 성장 비교’는 기본 접힘이다. 현재 장비·장착 스킬·배분에서 같은 능력치 3점을 더한 효과를 보여 주며 열림과 스크롤을 배분 중 유지한다.
- 비교의 증가율은 현재값 대비다. 예를 들어 힘 10에서 13으로 올리면 기본 피해는 1.4배에서 1.52배로 약 8.6%, 선택된 자원 피해는 1.1배에서 1.13배로 약 2.7% 증가한다. 적 상태·장비 발동까지 포함한 최종 피해 예측은 아니다.
- 미리보기는 플레이어 상태·장비 발동 횟수를 변경하지 않는다. 고정 교대와 비율 보호막 채우기를 일반 의지 생성 보정과 구분한다.

## 후보 비교와 한계

두 직업의 변경 전·후 격리 전투 8,352회와 관찰된 행동의 역할 대응 전투 15,552회, 합계 23,904회(11,952쌍)를 비교했다. 같은 예산·시드·합법 장착 조건을 사용했다. 전투 간 자원·상점·각인·성장을 유지하는 실제 완주 재현이 아니므로 실제 플레이어 승률로 사용하지 않는다. 원자료와 직업 상세는 저장소 밖 비공개 검증 문서에 보존한다.

격리 시험에서는 피해 성장으로 적의 행동 시점과 선택이 달라져 일부 결과가 악화된 쌍도 있었다. 해당 다섯 조건은 전후 행동을 다시 추적해 재현했다. 모든 조건에서 성능이 개선됐다고 결론 내리지 않는다. 적용 후 역할 대응 2,592회에서 무한 진행·자원 불변식 위반이 없었으나, 이전 3시드 시험과 표본 순환이 달라 완전 일치 검사로 사용하지 않는다.
