# 아이템 도감 — 10월 12일

- 메뉴의 아이템 도감에서 장비·소모품을 열람한다. 장비는 공개 장비 풀의 552종, 소모품은 현행 데이터의 53종이다. 시작 장비와 장비 풀에 없는 항목은 목록에 포함하지 않는다.
- 이름·효과·대가를 검색하고 첫 등장 챕터, 장비 부위·기본 등장 등급, 소모품 용도·고급 효과 유무로 좁힌다. 한 페이지는 24종이며 상세에서 돌아와도 검색·필터·페이지를 유지한다.
- 장비 효과·대가·배경 문장과 등급별 기본 수치 범위, 소모품 일반·고급 효과·사용 조건·한 칸 최대·판매 가격을 현재 데이터에서 읽는다. 등급별 수치 표가 모든 등급의 직접 드롭을 보장하지 않는다고 명시한다.
- 전투 중에도 읽기만 한다. 아이템 획득·장착·사용·발견 기록 변경 기능은 없다.
- 스킬 성장 공지와 도움말은 숫자 예시를 먼저 제시하고, 무기 성장을 따로 설명하도록 다듬었다. 계산은 변경하지 않았다.

## 검증

- `node tools/itembook-check.js`: 전체 공개 장비 풀 일치·중복 없음, 전 항목 상세 생성, 챕터·부위·등급·검색, 소모품 고급·보스 제외 조건, 페이지 한도, 읽기 전용 통과.
- `tools/itembook-browser.py`: 모의 서버에서 메뉴 진입·닫기·검색 중 입력 초점 유지·페이지·상세 복귀·필터·회복 용도·효과와 대가 표시·320/390/1280px·1.3배 글자 크기·전투 상태 불변 통과. 390px 화면을 직접 확인했다.
- `node tools/skill-growth-check.js`: 설명 변경 후 실제 피해 성장 계산 검사 통과.
- 공개·06a2 대응 파일과 릴리스 검사 통과.
