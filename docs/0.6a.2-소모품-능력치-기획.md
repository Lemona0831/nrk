# 0.6a.2 소모품 · 가방 · 능력치 (제안)

적 행동 개편(docs/0.6a.2-적-행동-기획.md)으로 싸움마다 받는 피해가 커졌다. 그 대신 싸움마다 작은 보상과 대처 수단을 주고, 성장의 고를 거리를 늘린다. 10월 4일 만든 사람 결정을 바탕으로 한 제안이다.

## 1. 정한 것 (만든 사람, 10월 4일)

| 항목 | 결정 |
| --- | --- |
| 전리품 | 쓰러뜨린 적마다 무언가 떨어질 확률을 둔다. 플라스크는 확률을 크게 낮추고, 골드와 가방에 들어가는 자잘한 소모품이 주로 떨어진다 |
| 소모품 | 1챕터에 30\~40종. 상점에서도 판다. 가방에서 꺼내 바로 쓰고, 차례 칸(빠른 · 주 행동)을 쓰지 않는다 |
| 가방 | 20칸 안팎으로 늘린다 |
| 장비 크게 늘리기 · 아주 드문 등급 | 모든 직업을 만든 뒤 한다 |
| 능력치 | 다섯 개(힘 · 민첩 · 지능 · 체력 · 의지), 처음 10점 · 레벨마다 3점 |

## 2. 전리품 \[가설\]

| 적 | 무언가 떨어질 확률 | 무엇이 (확률 안에서) |
| --- | --- | --- |
| 일반 | 30% | 골드 45%, 소모품 50%, 플라스크 한 칸 5% |
| 정예 | 60% | 골드 35%, 소모품 55%, 플라스크 한 칸 10% |
| 강적 · 보스 | 100%(둘) | 골드, 소모품, 플라스크 한 칸 15% |

- 소환된 적(하수인)은 떨구지 않는다(지금 경험치와 같다).
- 소모품 등급은 평범 · 고급 둘. 고급은 하층과 정예에서 더 잘 나온다.
- 지금의 장비 드롭(방을 이기면 고르는 보상)은 그대로 두고, 높은 등급 확률만 조금 낮춘다.

## 3. 소모품 쓰기

- 가방에서 누르면 바로 쓴다. 빠른 칸 · 주 행동을 쓰지 않는다.
- \[제안\] 한 차례에 소모품은 하나만(투척물 여러 개를 한 번에 쏟아붓지 않게). 만든 사람이 정한다.
- 같은 소모품은 한 칸에 겹친다(최대 5개). 가방 20칸은 장비와 소모품이 함께 쓴다.
- 전투 밖(방 사이)에서도 회복류는 쓸 수 있다.

## 4. 소모품 초안 (1챕터 36종, 이름과 수치는 가설)

| 갈래 | 소모품 |
| --- | --- |
| 회복 (8) | 마른 빵(생명력 6%), 약초 묶음(생명력 12%), 수도원 포도주(생명력 10%, 다음 공격 피해 −10%), 붕대(출혈 해제, 생명력 4%), 해독초(중독 해제), 찬물 한 병(화상 해제, 스태미나 +15), 성수 한 모금(해로운 상태 하나 해제), 꿀 덩이(라운드 끝마다 생명력 2%, 3라운드) |
| 기운 (4) | 각성 잎(스태미나 +30), 쓴 차(스태미나 +20, 약화 해제), 향 한 줌(이번 차례 빠른 칸 하나 더), 소금 결정(둔화 해제) |
| 막기 (6) | 나무 부적(다음에 받는 공격 피해 −40%), 연기 주머니(적 모두 다음 공격이 30% 확률로 빗나감), 낡은 방패 조각(보호막 +8), 기도 매듭(다음 해로운 상태 하나를 막음), 쇠 장갑끈(다음 강타 피해 −50%), 재 뿌리기(후열 적 하나의 다음 행동을 늦춘다) |
| 던지기 (8) | 투척 단검(한 적에게 피해, 후열까지), 기름 병(한 적에게 화상 3), 독 바늘(한 적에게 중독 3), 섬광 가루(한 적에게 붕괴 +30), 올가미(한 적에게 둔화 2), 깨진 성물(적 모두에게 작은 피해), 돌멩이(한 적의 몸 낮추기 · 버티기를 푼다), 종 조각(한 적의 예고를 한 번 끊는다: 모으던 강타 · 겨누기 · 도화선) |
| 꾀 (6) | 숫돌(다음 공격 피해 +25%), 쇠붙이 미끼(도둑이 이 전투에서 훔치지 못함), 깨진 거울(다음 축복 하나를 빼앗아 내게), 검은 향(적 하나의 축복 · 강화 해제), 표식 분필(한 적이 받는 다음 피해 +30%), 빈 성물함(쓰러뜨린 적의 전리품 확률 두 배, 이 전투) |
| 돈 (4) | 은화 주머니, 녹슨 성배, 촛대, 묵주 구슬(쓰지 못하고 팔기만 한다. 상점가 서로 다름) |

- 고급 소모품은 같은 이름에 수치가 크다(예: 약초 묶음 고급 = 생명력 20%).
- 상점은 소모품 몇 개를 늘 판다. 돈 갈래는 팔아 골드로 바꾼다.

## 5. 능력치 \[가설\]

| 능력치 | 하는 일 |
| --- | --- |
| 힘 | 근접 피해 +1%, 붕괴 +1% (1점마다) |
| 민첩 | 흘리기 감소 +0.5%p, 스태미나 +1, 치명타 확률 +0.4%p |
| 지능 | 지속 피해 +2%, 상태(중독 등)의 세기 |
| 체력 | 최대 생명력 +2 |
| 의지 | 보호막 · 회복 +2%, 해로운 상태가 걸릴 때 10%마다 하나를 버팀 \[가설\] |

- 포인트: 처음 10점, 레벨마다 3점(지금 6점, 2점).
- 직업마다 "추천 배분" 버튼을 둔다(암살자 민첩 · 지능, 파수꾼 힘 · 체력 · 의지).
- 저장본은 `migrateRun`에서 옛 세 능력치를 새 다섯으로 옮기고 남는 점수를 돌려준다. 자동 테스터의 배분 규칙도 바꾼다.

## 6. 치명타 (만든 사람 질문, 의견)

- **넣는 것을 제안한다. 다만 따로 찍는 능력치가 아니라, 민첩 · 장비에서 나오는 값으로.**
  - 치명타 확률: 기본 5%, 민첩 1점마다 +0.4%p, 장비로 더한다. 치명타 피해: 기본 150%, 장비로 더한다.
  - 다섯 능력치를 그대로 두어 배분이 더 복잡해지지 않는다. 장비 접사(치명 확률 · 치명 피해)가 생겨 2단계 장비 늘리기에서 고를 거리가 된다.
- **조심할 점:** 이 게임은 예고를 읽고 고르는 판단이 중심이라, 무작위로 크게 튀는 피해가 많으면 판단의 무게가 줄어든다. 그래서 기본 확률은 낮게 두고, 치명타가 판을 뒤집기보다 "가끔 기분 좋은 한 방"이 되게 한다.
- 선택지: 암살자는 붕괴한 적 · 취약한 적에게 치명 확률이 오르는 식으로 직업 맛을 줄 수 있다.
- 점수 모델(skillkit.js)에 치명 기대값을 더하고, 50상황 측정은 씨앗을 고정해 흔들림을 본다.

## 7. 순서

1. 능력치 다섯 · 치명타(정하면).
2. 가방 20칸, 소모품 엔진(가방에서 쓰기, 겹치기, 차례 칸을 쓰지 않음), 적마다 전리품.
3. 소모품 36종과 상점.
4. 보스(타락한 수도원장) 다듬기: 상세는 비공개 문서.
5. 던전 완주율(AI 5\~15%, 직업 차이 ±5%p)과 50상황을 다시 맞춘다.
