# 0.6a.2 소모품 · 가방 · 능력치

- **상태 (10월 4일):** 능력치 다섯을 넣었다(0.6a.2-22, 체력은 1점마다 생명력 +3으로 정함). 1챕터 AI 완주가 10% → 15%(암살자 16 · 파수꾼 13)로 올랐다. 소모품 · 가방 · 전리품을 넣었다(0.6a.2-23, `data/consumables.js`): 한 판에 골드 35 · 소모품 11.5개 · 플라스크 1.2칸을 줍고, 테스터는 소모품을 4.9개 쓴다. 완주 18%(암살자 21 · 파수꾼 15). 다음은 수도원장 다듬기와 완주율 다시 맞추기다.

적 행동 개편(docs/0.6a.2-적-행동-기획.md)으로 싸움마다 받는 피해가 커졌다. 그 대신 싸움마다 작은 보상과 대처 수단을 주고, 성장의 고를 거리를 늘린다. 10월 4일 만든 사람 결정을 바탕으로 한 제안이다.

## 1. 정한 것 (만든 사람, 10월 4일)

| 항목 | 결정 |
| --- | --- |
| 전리품 | 쓰러뜨린 적마다 무언가 떨어질 확률을 둔다. 플라스크는 확률을 크게 낮추고, 골드와 가방에 들어가는 자잘한 소모품이 주로 떨어진다 |
| 소모품 | 1챕터에 30\~40종. 상점에서도 판다. 가방에서 꺼내 바로 쓰고, 차례 칸(빠른 · 주 행동)을 쓰지 않는다 |
| 가방 | 20칸 안팎으로 늘린다 |
| 장비 크게 늘리기 · 아주 드문 등급 | 모든 직업을 만든 뒤 한다 |
| 능력치 | 다섯 개(힘 · 민첩 · 지능 · 체력 · 의지). 처음 15점 · 레벨마다 2점(만든 사람 안, 10월 4일 2차) |
| 치명타 | 넣지 않는다(만든 사람, 10월 4일 2차) |
| 소모품 2차 (만든 사람) | 소모품마다 서로 다른 상황을 풀어야 한다. 정해 둔 개수까지 겹친다. 적 하나에서 소모품이 2\~3개 나올 수 있다. 한 차례에 여러 개 쓸 수 있되 최대 3개, 같은 효과(같은 해제, 같은 강화)는 겹치지 않는다 |

## 2. 전리품 \[가설\]

| 적 | 무언가 떨어질 확률 | 무엇이 |
| --- | --- | --- |
| 일반 | 35% | 골드 40%, 소모품 55%(1\~2개), 플라스크 한 칸 5% |
| 정예 | 65% | 골드 30%, 소모품 60%(1\~3개), 플라스크 한 칸 10% |
| 강적 · 보스 | 100%(두 번 굴림) | 골드, 소모품(2\~3개), 플라스크 한 칸 15% |

- 소환된 적(하수인)은 떨구지 않는다. 소모품은 상층에서 평범, 하층과 정예에서 고급이 더 잘 나온다.
- 방을 이기고 고르는 장비 보상은 그대로 두고, 높은 등급 확률만 조금 낮춘다.

## 3. 소모품 쓰기

- 가방에서 누르면 바로 쓴다. 빠른 칸 · 주 행동을 쓰지 않는다. 한 차례에 최대 3개(만든 사람).
- 같은 효과는 겹치지 않는다: 같은 강화를 두 번 쓰면 남은 횟수만 새로 채우고, 이미 풀린 상태를 또 풀지 않는다(그때는 쓰지 못하게 버튼이 잠긴다).
- 같은 소모품은 한 칸에 겹친다. 겹치는 수는 소모품마다 다르다(아래 표). 가방 20칸은 장비와 소모품이 함께 쓴다.
- 회복 · 해제류는 전투 밖(방 사이)에서도 쓴다.

| 푸는 상황 | 소모품 | 효과 | 겹침 |

- 고급은 같은 이름에 수치가 크다(회복 · 피해 · 붕괴 수치만). 해제 · 막기류는 등급이 없다.
- 상점은 이 가운데 몇 가지를 늘 판다. 보스의 기믹을 푸는 전용 소모품은 두지 않는다(대처는 플레이어가 찾는다).

## 5. 능력치 \[가설\]

| 능력치 | 하는 일 (1점마다) |
| --- | --- |
| 힘 | 근접 피해 +1%, 붕괴 +1% |
| 민첩 | 흘리기 감소 +0.5%p, 스태미나 +1 |
| 지능 | 지속 피해 +2%, 거는 상태의 세기 |
| 체력 | 최대 생명력 +3 |
| 의지 | 보호막 · 회복 +2%, 해로운 상태를 버틸 확률 |

- **포인트: 처음 15점, 레벨마다 2점(만든 사람 안).** Lv5 23점, Lv10 33점, Lv20 53점. 처음에 직업 색을 바로 낼 만큼 주고(주 능력치 둘에 6\~7점씩), 뒤로 갈수록 조금씩 보탠다. 처음 점수가 지금(6점)의 두 배를 넘으므로, 1점의 값을 지금보다 낮춰 맞춘다.
- 직업마다 "추천 배분" 버튼(암살자 민첩 · 지능, 파수꾼 힘 · 체력 · 의지).
- 저장본은 `migrateRun`에서 옛 세 능력치를 새 다섯으로 옮기고 남는 점수를 돌려준다. 자동 테스터의 배분 규칙도 바꾼다.
- 치명타는 넣지 않는다(만든 사람).

## 6. 순서

1. 능력치 다섯(처음 15점, 레벨마다 2점).
2. 가방 20칸, 소모품 엔진(가방에서 쓰기, 겹치기, 차례 칸을 쓰지 않음), 적마다 전리품.
3. 소모품 36종과 상점.
4. 보스(타락한 수도원장) 다듬기: 상세는 비공개 문서.
5. 던전 완주율(AI 5\~15%, 직업 차이 ±5%p)과 50상황을 다시 맞춘다.
