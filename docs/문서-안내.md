## 문서를 고칠 때

- 게임 수치를 바꾸면 코드, 통합 기획서, 해당 분야 문서, 도움말을 같이 맞춘다. 배포는 [AGENTS.md](../AGENTS.md)를 따른다.
- 새 문서는 꼭 필요할 때만 만든다. 작은 변경은 기존 문서(통합 기획서, 개선 현황)에 한 줄로 더한다. 문서 머리에 공지를 쌓지 않는다.
- 직업 문서 맨 위 블록은 `node tools/docsync.js`로 갱신하고 `--check`로 확인한다. 링크는 `node tools/docs-links-check.js`로 확인한다.
- 보스·강적의 기믹과 대처, 해금 직업의 이름·규칙은 공개 문서에 쓰지 않는다.
