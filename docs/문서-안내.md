## 5. 문서를 고칠 때

- 수치를 바꾸면 **코드 → 통합 기획서 → 해당 직업 · 챕터 문서 → 변경 내역(`06a2/data/changelog.js`) → 도움말(`HELP`)** 순으로 맞춘다(CLAUDE.md "고칠 때 순서").
- 직업 문서 맨 위 블록은 `node tools/docsync.js`로 갱신하고 `--check`로 확인한다.
- 결과표(`검증-결과.md`)는 손으로 고치지 않는다(`node tools/vresult.js`).
- 보스 · 강적의 기믹과 대처, 해금 직업의 이름 · 규칙은 공개 문서에 쓰지 않는다.
