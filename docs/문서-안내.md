## 문서를 고칠 때

- 게임 수치를 바꾸면 루트·06a2의 대응 코드, 통합 기획서, 해당 분야 문서·검증 근거, 도움말을 맞춘다. 배포 절차는 [AGENTS.md](../AGENTS.md)를 따른다.
- 문서 정리만으로 게임 릴리스나 플레이어 업데이트 항목을 추가하지 않는다. 이번 게임 조정은 최신 사용자 요청에 따라 시간·분류별로 모두 표기한다. 개인 기록·운영 변경은 넣지 않는다([문체 기준](문체-기준.md), [최신 결정](만든사람-결정.md)).
- 직업 문서 맨 위 블록은 `node tools/docsync.js`로 갱신하고 `--check`로 확인한다.
- 결과표(`검증/검증-결과.md`)는 손으로 고치지 않는다(`node tools/vresult.js`).
- 보스 · 강적의 기믹과 대처, 해금 직업의 이름 · 규칙은 공개 문서에 쓰지 않는다.
- 상세 밸런스 보고서의 생성 경로는 `../nrk-private/제안/`이다. 공개 요약과 비공개 원문을 별도로 유지한다.
- 링크·생성 경로 확인은 `node tools/docs-links-check.js`, 코드 기준 블록 확인은 `node tools/docsync.js --check`로 한다. 과거 누적 결과표는 이번 정리 때문에 다시 생성하지 않는다.

- 여섯 개선의 근거·검증 범위: [검증/여섯-개선-근거.md](검증/여섯-개선-근거.md).
