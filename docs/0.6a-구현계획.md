# 0.6a 구현 계획

기획서 11절(0.6: 3챕터 캠페인)의 첫 단계인 0.6a를 만드는 순서다. 0.6a는 0.6의 모든 시스템과 1챕터를 담는다. 보스·강적 상세는 저장소 밖 비공개 문서(nrk-private/보스.md)를 따른다.

## 순서를 이렇게 잡은 이유

- 화면(1)을 앞에 둔다. 위험이 낮고, 이후 모든 화면이 새 테마 위에서 만들어진다.
- 저장(2)과 장비 바탕(3)을 아이템 효과(5)보다 먼저 한다. 장비가 한 곳에만 있는 규칙(9.2절)이 흔들리면 100종을 넣은 뒤에 고치기 어렵다.
- 전투 규칙(4)을 아이템보다 먼저 바꿔 새 기준선 승률을 잰다. 그래야 아이템이 균형을 얼마나 바꾸는지 따로 볼 수 있다.
- 자동 테스터는 단계 0에서 나눈 파일을 읽게 고치고, 단계 11에서 새 판 구조에 맞게 다시 쓴다. 그사이에는 B0.5 방 구성으로 전투 규칙만 잰다.
