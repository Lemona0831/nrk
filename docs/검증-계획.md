# 1만 회 이상 검증 계획 (목표 7단계)

- **상태:** 10월 8일 계획. 실행은 3챕터 · 2챕터 장비가 들어간 뒤 한 번에 한다(그 전 결과는 다시 재야 해서 세지 않는다). 지금까지 쌓인 측정(관문 · 직업별 측정)은 설계 반복용이고 이 1만 회에 넣지 않는다.
- **근거:** docs/목표-1-3챕터.md 7단계. "일부 조건만 반복한 1만 회를 전체 검증으로 주장하지 않는다", "테스트에 쓰지 않은 시드로 다시 확인한다", "테스터 전략이 바뀌면 이전 결과와 바로 비교하지 않는다".

## 2. 배정 (총 던전 판 수와 전투 수를 따로 센다)

## 3. 결과를 나눠 보는 축 (목표 7단계 목록)

판마다 남기는 것: 직업, 성향, 갈래(`run.focus`, 트리 포인트의 절반 이상을 쓴 갈래), 길, 모드, 씨앗, 챕터별 도달 층, 결과, 레벨, 장착 스킬 · 장비, 전투 기록(`fightRec`: 받은 피해 출처, 행동 종류, 붕괴, 흘림, 방어, 소모품, 큰 공격, 예고 뒤 내 차례), 골드 · 소모품 흐름.

| 지표 | 나누는 축 |
| --- | --- |
| 층별 도달률, 완주율, 보스 도달률 · 보스 승률 | 직업 × 갈래 × 챕터 × 모드 |
| 사망 원인과 예고 뒤 대응 가능 여부 | 직업 × 챕터 × 방 종류 × 적 |
| 받은 피해, 회복 · 소모품 · 골드의 수급과 사용 | 직업 × 챕터 |
| 전투 길이, 행동 종류, 추가 행동(사냥꾼 두 번째 차례, 빠른 칸 하나 더)과 행동 차단(봉인 · 새김 · 기절) | 직업 × 갈래 |
| 실제로 낀 스킬 · 장비의 빈도, 쓰지 않는 칸 | 직업 × 갈래 |
| 특정 희귀 · 영웅 · 전설 장비나 빌드가 결과를 지배하는지 | 장비마다 낀 판 · 안 낀 판 |
| 일반 · 가혹 모드의 위험 · 보상 차이 | 모드 × 직업 |

## 4. 다시 잴 때의 규칙

- 테스터 판단(qa.js · dgqa.js)이 바뀌면 그 판의 결과를 이전 결과와 바로 비교하지 않는다. 바뀐 것을 적고 기준(1챕터 720판, 직업별 10판)을 다시 만든다. 지금 기준 파일은 `scratchpad/base/dg40_fix.json`(옛 직업 셋, 10월 7일 0.6a.2-51 이후)이다.
- 결과는 한 번에 만든 표 하나로 낸다(`docs/검증-결과.md`). 표마다 판 수와 씨앗 범위를 적는다.
- 테스터가 못 하는 것(아이템을 받고 행동을 바꾸기, 두 수 앞)은 사람 플레이 질문(5절)으로 넘긴다.

## 5. 사람 플레이에서 볼 질문 (직접 플레이 · 지인 기록)

- 규칙 이해: 직업 규칙(열충격, 교대, 기, 연속 행동, 해금 직업 셋)을 첫 전투에서 이해했는가. 어디서 막혔는가.
- 선택의 이유: 갈래 · 길 · 문 · 장비를 고른 까닭. 같은 칸만 계속 고르는가.
- 실수의 납득: 쓰러졌을 때 무엇 때문인지 아는가(쓰러짐 화면의 결정타가 맞았는가). 예고를 보고도 대응하지 못한 차례가 있었는가.
- 다시 하고 싶은 이유: 다른 갈래 · 직업 · 가혹 · 표식을 해 보고 싶은가.
- 숨겨진 직업: 해금 조건을 알아챘는가, 우연이었는가.
- 보스: 보스마다 직업별로 이기는 길이 다르게 느껴졌는가.
