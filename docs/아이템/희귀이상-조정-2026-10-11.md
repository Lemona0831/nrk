# 희귀 이상 장비 조정 (2026-10-11)

기본 장비 수치와 등급별 성장은 유지합니다. 반복 발동과 실제로 지불하는 대가를 조정합니다. 기존 장착·보관 장비에도 현재 효과가 적용됩니다.

| 장비 | 변경 | 유지 |
| --- | --- | --- |
| 피를 마시는 칼 | 차례당 흡혈 상한 제거, 최대 생명력 −10% 추가 | 실제 피해 흡혈 10%, 플라스크 회복 −20% |
| 피의 계산서 | 부족 시 최대 생명력 4% → 6% | 남은 스태미나 모두 지불, 생명력 비용 감소 적용 |
| 참회의 장창 | 40% → 실제 깎은 생명력의 25%, 행동마다 한 번 | 전열을 꿰뚫는 후열 공격, 강공격 비용 +5 |
| 성인의 성배 | 추가 빠른 행동 발동은 내 차례마다 한 번 | 모든 플라스크 충전 −1 |
| 공허의 반지 | 쿨타임 감소 내 차례마다 한 번 | −1, 쿨타임 최소 2, 스킬 피해 −15% |
| 군주의 성배 | 실제 플라스크 회복량으로 기본 보호막 생성 | 의지·장비 생성 보너스, 보호막 상한, 생명력 충전 −1 |
| 두 번째 손 | 주 행동 피해 −15% → 모든 직접 피해 −15% | 빠른 행동 추가 1회 |
| 잔광의 목걸이 | 행동마다 한 번, 소환물·뼈 더미 제외 | 종류별 절반 올림 최대 6, 받는 해로운 상태 +1 |

차례 제한은 빠른 행동과 주 행동이 공유합니다. 장창·잔광의 행동 제한은 연타와 같은 행동의 복수 처치에 공유합니다. 흡혈은 차례당 상한 없이 실제로 깎은 적 생명력의 10%를 회복하며, 내 최대 생명력까지만 회복합니다. 초과 피해 흡혈 오류 수정은 유지합니다.

검증: tools/rare-equipment-balance-check.js에서 조건·반복·차례 전환·실제 지불/회복량을 확인합니다. 전체 장비를 일괄 약화한 것이 아니며 미조정 장비는 기존 효과를 유지합니다.
