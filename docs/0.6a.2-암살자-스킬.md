# 0.6a.2 암살자 스킬 (시범 직업)

0.6a.2 개편(docs/0.6a.2-개편-기획.md)의 시범 직업 암살자의 시작 스킬 2개와 스킬 트리 액티브 30개다. 06a2 사이트(https://lemona0831.github.io/nrk/06a2/)에 들어가 있고, 자동 테스터로 잰 값으로 한 번 다시 맞췄다(10월 3일, 4절).

- 스킬 데이터는 `06a2/data/skills.js`, 점수와 설명 문장 규칙은 `06a2/data/skillkit.js` 한 곳에 있다. 게임 화면(트리, 설명창)과 `node tools/skillscore.js`(점수표, `md`를 붙이면 아래 표)가 같은 파일을 읽는다. 이 문서의 표는 그 도구가 만든 것이다.
- 갈래: 독사(작은 독을 자주 걸고 키운다), 격발(쌓인 중독을 한 번에 피해와 붕괴로), 그림자(흘리기 중심).

## 3. 액티브 30개

머리줄은 대상 · 행동 시간 · 충전이다. 설명의 키워드(중독, 붕괴, 터뜨리기, 흘리기)는 화면에서 눌러 뜻을 본다.

- **중독 N:** 시간마다 N 피해를 주고 1 줄어든다. 걸면 N만큼 오른다(상한 20).
- **터뜨리기:** 남은 중독이 앞으로 줄 피해(중독 N이면 N + (N−1) + … + 1)를 지금 한꺼번에 준다. "3만 터뜨린다"는 위에서 세 겹만 주고 중독을 3 줄인다. "터뜨린 피해 ×2"는 그 총량의 두 배다.
- **충전:** 전투를 가득 찬 채 시작하고, 쓰면 1 줄고, 적힌 조건이 일어나면 1 찬다. 스킬은 자기 효과로 일어난 조건으로는 차지 않는다.
