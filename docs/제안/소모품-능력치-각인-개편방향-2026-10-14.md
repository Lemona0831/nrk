# 소모품·능력치·각인 개편 방향 (2026-10-14)

[능력치·각인·소모품 재검토](능력치-각인-소모품-재검토-2026-10-14.md)의 다음 단계다. 개발자 답변(2026-10-14)을 받아 **개편 방향과 결정할 질문**을 정리한다. 아직 규칙·수치는 바꾸지 않았다. 질문의 답을 받은 뒤 한 번에 하나씩 바꾼다.

| 주제 | 답변 |

| 각인의 대가 | 나중에 정함 |

## 1. 소모품 개편

### 1-1. 지금 구조의 뿌리 문제

소모품이 **행동 경제 밖**에, 그리고 **빌드 밖**에 있다.

- 행동 밖: 전투 중 사용에 행동 칸이 들지 않고(차례당 3개), 쿨다운·전투당 한도가 없다. 전투 밖은 횟수 제한도 없다.
- 빌드 밖: 공격 소모품은 능력치·장비·각인 보정을 받지 않고 레벨로만 커진다. 누가 써도 같은 일을 한다.

그래서 소모품이 직업 차이를 지운다. 회복은 플라스크를 대신하고(약초 3개 = 행동 없이 36%, 고급 60%), 해제·방해 소모품은 해제 스킬과 직업 약점과 적 기믹을 값싸게 무력화하며, 공격 소모품은 스킬 한 번 수준의 피해를 낸다. 반대로 공급은 무작위 드롭과 보스 뒤 상점뿐이라, 필요한 것을 필요한 때 얻지 못한다(플레이어 설문: "얻고 싶은 소모품을 줍지 못해 체력을 채우거나 기믹을 수행하지 못함").

### 1-2. 개편 목표(제안)

1. **소모품은 준비와 위기 대응의 도구다.** 직업 대신 싸워 주지 않는다.
2. **회복의 중심은 플라스크다.** 약초는 플라스크를 보조한다.
3. **쓰는 순간 대가가 있다.** 행동이든 기회든.
4. **공급은 고를 수 있다.** 무작위만으로 결정되지 않는다.
5. **종류는 역할이 겹치지 않게 줄인다.** 화면에서 찾고 쓰기 쉽게.

### 1-3. 손잡이(구조 선택지)

| 손잡이 | 선택지 | 제안 |
| --- | --- | --- |
| 휴대 | 장비와 가방 공유(현행) / **전투용 주머니를 따로**(몇 칸, 칸마다 한 종류) | 주머니 분리. 전투 전에 무엇을 챙길지가 준비 판단이 되고, 회복 묶음이 장비 칸을 빼앗지 않는다 |
| 전투 중 사용 비용 | 행동 없음·차례당 3개(현행) / **빠른 행동 하나** / 행동 없음·전투당 상한 | 빠른 행동. 플라스크와 같은 줄에 선다. 차례당 3개 규칙이 사라진다 |
| 약초 | 현행 + 제한 / **플라스크 충전 재료**(전투 밖에서 약초로 플라스크를 채움) / 전투 밖 전용 / 천천히 차는 회복 | 충전 재료. 회복 총량은 플라스크 상한이 정하고, 약초는 보급 수단이 된다 |
| 공격 소모품 | 현행 / 능력치 연동 / 전투당 1회 / **피해 대신 기회를 만드는 효과로**(붕괴·약화·표식) | 기회형. 스킬을 대신하지 않고 스킬을 돕는다 |
| 기믹 대응 | 무력화(현행) / **완화**(절반·한 번만) / 제거 | 완화. 기믹을 읽고 대응하는 판단을 남긴다 |
| 종류 | 53종(현행) / **역할별로 대폭 정리** | 해제 6종은 하나 또는 둘로, 방해 13종은 기믹 완화형 몇 개로 |
| 공급 | 무작위 드롭·보스 뒤 상점(현행) / **드롭에서 고르기 + 중간 보급 방 + 상점 재고 유한** | 셋 모두. 중간 보급 방은 새 방 종류로 넣는 데 이미 동의함 |
| 챕터 전용 | 계속 남음(현행) / **다음 챕터로 넘어가면 정산에서 골드로 바뀜** | 골드 전환. 챕터 기믹 대비 수요를 그 챕터 안에 묶는다 |

### 1-4. 함께 바뀌는 것

- 각인 "넉넉한 손"(한 차례 소모품 +1)과 향 한 줌(빠른 칸 +1)은 사용 비용을 바꾸면 의미가 달라진다.
- 기존 세이브의 소모품 묶음·즐겨찾기를 새 구조로 옮기는 규칙이 필요하다.
- UI: 상점·가방·전투 소모품 버튼. [플레이어 UI 요구](플레이어-UI-개선요구-2026-10-13.md)의 소모품 찾기·사용 불편과 함께 다룬다.
- 검사 도구: `cons-stack-space-check`, `cons-fill-check`, `cons-overflow-check` 등.
- 초반 난이도: 1챕터 사망 중 회복 재고 부족형과 반응 지연형([재검토 §4-2](9직업-전투성장-재검토-2026-10-14.md))이 섞여 있다. 회복에 행동 비용을 주면 반응 지연형이 늘 수 있어, 중간 보급 방과 같이 들어가야 한다.

### 1-5. 시험

같은 시드의 연속 던전(`dgqa`)과 로그 지표로 전후를 본다: 판당 회복 총량과 그중 소모품 몫, 챕터별 사망과 그 유형, 플라스크 사용 비율, 잔여 골드, 보스전 행동 수(`boss-replica`).

## 2. 능력치

### 2-1. 목표를 측정 가능한 말로

- **리스크** = 대응하지 못한 실수(예고된 강타를 막지도 피하지도 못함)를 몇 번 버티는가.
- **리턴** = 처치 속도(보스까지 행동 수).

| 빌드 | 리턴 | 리스크 |
| --- | --- | --- |
| 몰아넣기 | 가장 빠름 | 실수 한두 번이 치명적 |
| 분산 | 몰아넣기보다 느리지만 적절(제안: 행동 수 1.3\~1.4배 이내) | 실수를 여러 번 버팀(제안: 무대응 강타 3번 이상) |

### 2-2. 지금은 왜 안 되는가

- 리턴: 분산이 너무 느리다. 보스 재생에서 추천 배분은 몰아넣기보다 처치가 약 2배 느렸다.
- 리스크: 몰아넣기에 위험이 없다. 빠른 처치에서 보스 예고가 0\~1번밖에 나오지 않고(대응할 일이 생기기 전에 끝남), 2·3챕터 사망은 0건이다.

### 2-3. 손잡이

- **리스크를 실재하게:** 보스 각 단계에서 예고된 공격이 한 번은 나오게 한다([처치 속도 측정](../검증/보스-처치속도-측정-2026-10-14.md)의 A안). 그러면 몰아넣기도 예고에 대응해야 하고, 대응하지 못하면 생명력이 낮은 빌드가 위험해진다. 능력치 숫자를 건드리지 않고 리스크를 만든다.
- **분산의 바닥을 올리기:** 방어 능력치가 생존 외에 쓸모를 갖게 한다(예: 체력은 강타 버티기·붕괴 저항, 의지는 회복·보호막·상태 저항을 더 크게). 공격의 선형 성장은 그대로 두어 몰아넣기의 리턴을 지킨다.
- (보조) 공격 능력치 고점에서 감소 수확. 리턴을 깎으므로 위 둘로 부족할 때만.

## 3. 각인을 스킬 트리로

### 3-1. 두 안의 비교

| | A. 공용 패시브 트리를 따로 | B. 직업 트리를 패시브·액티브 혼합으로 재구축 |
| --- | --- | --- |
| 하는 일 | 지금 각인을 얻는 시점(정산 2회·야영지 2회)을 패시브 점수로 바꾸고, 공용 각인 24개를 한 판에 배치 | 직업 각인 27개와 새 패시브를 9직업 27갈래의 트리 칸으로 |
| 좋은 점 | 계획할 수 있고 기회비용이 생긴다. 직업 트리를 건드리지 않는다 | 직업 정체성 강화. 상급 스킬 채용 가치·사냥꾼 갈래 혼합 문제를 같이 풀 수 있다(갈래 투자에 패시브 보상) |
| 위험 | 트리가 둘이 되어 화면 부담(특히 모바일). 무작위 제시가 사라지면 로그라이크 변주가 준다 | 9직업 전체 재작업, 스킬 데이터·도구·문서 재작성, 전 직업 재측정 |
| 크기 | 중간 | 큼 |

### 3-2. 제안: 단계적으로

1. **먼저 A.** 공용 각인을 공용 패시브 판으로 옮기고, 획득 시점은 그대로 둔다(정산·야영지에서 점수). 직업 각인 27개는 임시로 공용 판의 직업 칸으로 둔다.
2. **그다음 B.** 직업 트리를 재구축할 때 직업 칸을 갈래 트리로 옮긴다. 복사본 각인 정리와 한 직업만 있는 선물 각인 정리를 이때 같이 한다.

## 4. 순서 제안

1. **소모품 개편**: 지금 게임을 가장 많이 왜곡한다. 답을 받은 뒤 회복 → 사용 비용·주머니 → 공격·기믹 → 공급 순으로 한 단계씩.
2. **보스 단계 최소 유지(A안)**: 능력치 리스크의 전제.
3. **능력치**: 리스크가 생긴 뒤 분산의 바닥을 맞춘다.
4. **각인 → 트리**: 가장 크다. 1\~3의 결과를 본 뒤.
