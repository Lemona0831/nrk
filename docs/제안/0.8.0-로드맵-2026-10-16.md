# 0.8.0 로드맵 — 2026-10-16

만든 사람 결정(10월 16일): 다른 플레이어 테스트는 유산 1차만이 아니라 **0.8.0 전체를 만든 뒤**에 받는다. 이 문서는 [유산 · 방사형 트리 설계안](유산-방사트리-설계안-2026-10-15.md)의 시제품 단계를 구현 단위로 나눈 순서다. 모든 작업은 `proto-yusan` 브랜치와 시제품 사이트(`nrk-test/proto/`)에서 한다. 공개 게임 · 테스트 서버는 0.8.0 확정 전까지 그대로다.

## 0.8.0에 들어가는 것

1. 유산(스킬 행동력): 쿨타임 대신. **끝남**(1차 · 1차-b · 화면)
2. 패시브 방사 트리: 각인 + 능력치 흡수, 6방향(화력 · 생존 · 유지력 · 제어 · 기민 · 계승), 큰 각인은 챕터 보상
3. 액티브 방사 트리: 갈래 3방향, 스킬 노드 + 강화 노드
4. 경험치 곡선 다시 맞춤(1챕터 끝 Lv5에서 6, 2챕터 10에서 11, 3챕터 15에서 16)
5. 9직업 트리 재구성: 마검사는 기존에 가깝게, 나머지는 기반을 지키고 살리지 못한 것을 살림
6. 3챕터 난이도(적 생명력 상층 ×1.25 · 하층 ×1.5, 보스 ×1.1): 이미 `proto-yusan`에 들어 있음
7. 도움말 · 업데이트 내역 · 저장 호환

## 순서의 이유

- 트리 **엔진(2)과 화면(3)은 9직업이 함께 쓰는 틀**이라 직업 내용보다 먼저 한다. 마검사 하나로 틀을 검증하고(4) 나머지에 넓힌다(5, 6).
- 직업별 트리 내용은 설계 판단이 많아서 **직업마다 초안을 만든 사람이 먼저 본다.** 승인된 것만 넣는다.
- 전체 균형(7)은 9직업이 모두 들어간 뒤에 한 번에 본다. 직업 하나씩 맞추면 서로의 기준이 흔들린다.
