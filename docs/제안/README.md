보스 대응·해금 직업 상세를 포함한 전체 원문은 로컬의 `../../../nrk-private/제안/`에 보관한다. 공개 요약과 원문은 파일 이름이 같다. 생성 도구는 전체 원문을 비공개 경로에 쓰며 이 요약을 덮어쓰지 않는다.

후보를 실제 적용할 때는 제안서를 고쳐 과거 결과를 바꾸지 않는다. 현행 기획서와 별도 검증 기록에 적용 내용·기준 코드·새 측정을 남기고, 이 목록의 상태를 갱신한다.
