# 제안서 안내

여기는 **분석과후보의 공개 요약**이다. 이전 실험 결과는 보존하고, 이후 일부 적용된 변경은 별도 검증 문서로 연결한다. 현재 구현은 [개선 현황](../검증/0.7.0-개선-현황.md), 현행 규칙은 [통합 기획서](../현행-통합-기획서.md)를 따른다.

| 제안 | 기준 | 상태 |
| --- | --- | --- |
| [마검사 능력치·빌드](마검사-능력치-빌드-밸런스-2026-10-12.md) | 2026-10-12, 기준 코드 `36f49c5`, 통제 전투 16,704회 | 후보 미적용 |
| [전체 직업 능력치](전체-직업-능력치-밸런스-2026-10-12.md) | 2026-10-12, 기초 비교 전투 39,888회. 후속 오류 수정·선택 자원 성장·공통 투자 비교는 별도 검증 | 일부 적용·9직업 개별 개선 진행 |

보스 대응·해금 직업 상세를 포함한 전체 원문은 로컬의 `../../../nrk-private/제안/`에 보관한다. 공개 요약과 원문은 파일 이름이 같다. 생성 도구는 전체 원문을 비공개 경로에 쓰며 이 요약을 덮어쓰지 않는다.

후보를 실제 적용할 때는 제안서를 고쳐 과거 결과를 바꾸지 않는다. 현행 기획서와 별도 검증 기록에 적용 내용·기준 코드·새 측정을 남기고, 이 목록의 상태를 갱신한다.
