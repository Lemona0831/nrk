# 소모품 개편 설계안 v1 (2026-10-14)

[개편 방향](소모품-능력치-각인-개편방향-2026-10-14.md)에 대한 개발자 답변(2026-10-14)을 반영한 **구체 설계안**이다. 숫자는 로그 근거를 붙인 **제안값**이며 승인 전이다. 게임 규칙은 아직 바꾸지 않았다.

## 0. 확정된 방향 (개발자 답변)

| 항목 | 결정 |
| --- | --- |
| 역할 | 일상 전투 자원. 직업 약점은 소량만 보완 |
| 가방 | 장비 가방과 소모품 가방 분리. 소모품 가방 5칸, 무게로 묶음 기준 정의 |
| 사용 비용 | 행동을 쓰지 않음. 차례당 1개, 전투당 상한(값은 검토) |
| 약초 | 플라스크 충전 재료. 개수와 시장 가치를 확실히 정함 |
| 공격 소모품 | 약초와 같은 규칙. 피해 대신 기회 만들기 |
| 기믹 대응 | 완화(한 번만 막기 또는 절반) |
| 종류 | 역할별로 대폭 축소 |
| 공급 | 몬스터 드롭과 **던전 중간 상점**(예정). 중간 보급 방은 만들지 않음 |
| 챕터 전용 | 챕터를 넘어가면 정산에서 골드로 자동 반환 |
| 가혹 | 더 강하게 제한 |

## 1. 근거: 지금의 회복 경제 [사실, 로그]

챕터를 끝까지 깬 판 중 행동 기록이 남은 11개 챕터(행동 기록은 최근 900개만 저장돼 긴 판의 앞 챕터는 빠짐):

| 지표 | 챕터당 평균 |
| --- | --- |
| 소모품 회복(약초·빵·수액) | 최대 생명력의 약 **2.0배** |
| 생명력 플라스크 회복 | 약 **0.6배** |
| 쓸 수 있던 플라스크 | 약 4.6칸(시작 3 + 야영지 1 + 샘 약 0.6) = 1.4배 |
| 약초 획득(전리품·보상, 상점 구매 제외) | 3~20개, 중앙값 약 **9개** |

- 플라스크를 쓸 수 있는 양의 절반도 안 썼다. 행동이 드는 플라스크 대신 행동이 안 드는 약초를 먼저 쓴 것이다.
- 가혹 마검사는 2·3챕터에서 소모품만으로 챕터당 4.5배를 회복했다(가장 큰 의존).

## 2. 가방

| 항목 | 제안 |
| --- | --- |
| 구조 | 장비 가방(현행 20칸에서 소모품을 뺀 것)과 **소모품 가방 5칸**을 분리 |
| 묶음 | 소모품마다 무게 `w`. 한 칸의 무게 한도 **10**. 한 칸에 담기는 수 = ⌊10 / w⌋ |
| 무게(예) | 약초 2(5개), 기회·방어류 3(3개), 기믹 완화류 3~5(2~3개), 탈출·특수 5(2개) |
| 같은 종류 | 한 종류가 여러 칸을 써도 된다(약초만 5칸 = 25개도 가능하지만 다른 것을 못 든다) |
| 판매품(은화·성배 등) | 소모품 가방이 아니라 **줍는 즉시 골드**로 바꾼다(칸 경쟁 제거) — 질문 Q5 |

가방 5칸이 전투에서 쓸 수 있는 소모품 총량의 첫 번째 제한이 된다.

## 3. 사용 규칙

| 항목 | 일반 | 가혹 |
| --- | --- | --- |
| 행동 비용 | 없음 | 없음 |
| 차례당 | 1개 | 1개 |
| 전투당 상한 | **5개** | **3개** |
| 전투 밖 | 약초를 플라스크로 바꾸기만 가능(아래 4). 다른 소모품은 전투 중에만 | 같음 |

- 지금의 "차례당 3개"와 각인 "넉넉한 손"(+1)은 없어진다. 넉넉한 손은 각인 트리 개편 때 다른 효과로 바꾼다.
- 향 한 줌(빠른 칸 +1)은 행동 경제를 직접 늘리므로 없애거나 전투당 1회로 둔다 — 질문 Q4.
- 보스전도 같은 상한을 쓴다.

## 4. 약초 → 플라스크

| 항목 | 일반 | 가혹 |
| --- | --- | --- |
| 교환 | 전투 밖에서 **약초 3개 → 생명력 플라스크 1칸** | **약초 4개 → 1칸** |
| 상한 | 플라스크 최대 충전(기본 3)을 넘지 못한다 | 같음 |
| 전투 중 | 약초는 쓰지 못한다. 회복은 플라스크(빠른 행동)로 | 같음 |
| 고급 약초 | 없앤다(약초는 한 종류) | 같음 |
| 마른 빵 | 없앤다 | 같음 |
| 선인장 수액(3챕터) | 화상 해제만 남기고 회복은 뺀다(기믹 완화류로) | 같음 |

**수치 근거.**
- 약초 획득 중앙값 약 9개/챕터 → 일반 약 3칸, 가혹 약 2칸의 추가 플라스크다.
- 일반 기준 챕터당 쓸 수 있는 회복은 플라스크 4.6칸 + 약초 3칸 ≈ 7.6칸 × 30% ≈ **최대 생명력의 2.3배**다. 지금 실제로 쓴 평균(소모품 2.0 + 플라스크 0.6 = 2.6배)보다 조금 적다.
- 그 회복은 이제 모두 **빠른 행동**이 든다. 그래서 체감 회복량은 더 줄어든다. 가혹은 플라스크 4.6칸 + 약초 약 2.3칸 ≈ **약 2.1배**다.
- 플라스크 상한 3과 소모품 가방 5칸이 "쟁여 두기"를 막는다.

**시장 가치.**

| 항목 | 1챕터 | 2챕터 | 3챕터 | 근거 |
| --- | --- | --- | --- | --- |
| 약초 구매가 | 12 | 18 | 27 | 현행 유지(×1.5/챕터). 플라스크 1칸 = 36·54·81골드 |
| 약초 판매가 | 5 | 7 | 11 | 현행 40% |
| 상점 약초 재고 | 방문당 **6개**(가혹 3개) | 같음 | 같음 | 3챕터 완주 4판 중 3판이 1832~4244골드를 남겼다. 재고가 없으면 골드로 회복을 무한히 산다 |

## 7. 기존 세이브

- 없어지는 소모품은 판매가로 골드 환산. 합쳐지는 것은 새 종류로 개수 이전(소모품 가방 5칸을 넘으면 넘친 몫은 골드).
- 마른 빵·고급 약초는 약초로 환산(빵 1 = 약초 1, 고급 약초 1 = 약초 2).
- 즐겨찾기는 새 종류 기준으로 다시 맞춘다.

## 8. 단계별 적용 계획

| 단계 | 내용 | 시험 |
| --- | --- | --- |
| 1 | 소모품 가방 분리·무게 묶음·판매품 즉시 골드·세이브 이전 | 저장·불러오기·이전 규칙, 가방 화면(360·390·1280px) |
| 2 | 사용 규칙(차례당 1·전투당 상한) | 전투 소모품 사용 시험, 보스 재생 전후 |
| 3 | 약초 → 플라스크, 빵·고급 약초 정리 | 연속 던전 전후: 챕터별 사망·회복 총량·잔여 골드 |
| 4 | 종류 정리·효과 변경(기회·완화) | 소모품별 효과 발동 시험, 기믹 대응 시험 |
| 5 | 공급(드롭 표·상점 재고·챕터 전용 환산) | 연속 던전 공급량, 상점 구매 기록 |

1~5가 모두 끝나야 균형이 맞는다. 중간 단계를 그대로 공개하면 한동안 회복이 너무 적거나 많은 상태가 된다 — 질문 Q1.
