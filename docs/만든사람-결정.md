# 만든 사람이 정할 것 (모음)

- **상태:** 10월 8일 정리. 여러 문서에 흩어진 "만든 사람이 정할 것"을 한곳에 모았다. 결정이 나면 이 표의 "지금(잠정)" 칸을 결정으로 바꾸고 출처 문서도 고친다.
- **읽는 법:** "지금(잠정)"은 결정이 나기 전까지 코드 · 문서가 따르는 값이다. 결정 없이 바꾸지 않는다.
- **공개 범위:** 숨겨진 직업은 이름 없이 "해금 1 · 2 · 3"으로 적는다. 보스 · 강적 기믹에 걸린 질문은 비공개 문서(`../nrk-private/`)의 마지막 절에 있고 여기에는 "비공개"로만 적는다.
