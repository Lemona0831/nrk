# 작업 기록 (10월 2일 기준)

## 지금 게임 (B0.5)

- 직업 8종: 광전사, 사냥꾼, 비전술사, 성전사, 암살자, 암흑술사, 사제, 상흔술사. 직업마다 직업 규칙 1개, 직업 전용 스킬 3개, 직업 기술 1개
- 스킬: 공용 13개 + 직업 전용 3개 중 세 칸. 무기 기술은 스태미나, 주문은 마나, 피의 기술은 생명력을 쓴다
- 능력치: 시작 6점, 5번 방 뒤 3점. 힘·민첩·지능, 1점마다 규칙 하나
- 아이템: 막힘 해결용 3종(5번 방 앞), 자발 시험용 25종(1·3·7번 방에서 둘 중 하나). 맞지 않는 빌드에는 내밀지 않는다
- 독: 슬레이 더 스파이어 방식(걸 때마다 +1, 시간마다 수치만큼 피해 후 1 감소). 독 격발은 남은 피해 전부와 붕괴
- 흘리기: 고른 적의 다음 공격 피해 60% 감소, 강타면 붕괴 +25
- 도망은 방을 건너뛰지 않고 물러난다. 일반 방 40T, 보스 35T부터 광폭, 10T마다 짙어짐

## 남은 문제

- 판마다 "고민한 순간이 없었다"가 많다. 앞쪽 방(1~4번)이 쉽다는 의견과 이어진다. 지인 기록이 모이면 직업별 1~4번 방 손실을 비교해 판단한다
- 플라스크를 끝까지 거의 쓰지 않는다
- 잔향의 매듭, 사슬 장갑, 회복·방어형 전용 스킬(상처 봉합, 신성 오라)은 자동 테스트로 판단이 어렵다
- 막힘 해결용 아이템이 5번 방 통과율을 크게 바꾸지 못한다(자동 테스터 한계일 수 있음)
