# 1-3챕터 목표와 결과 (0.7.0까지)

10월 5일 만든 사람이 세운 목표와, 0.7.0까지의 완료 상태를 한 문서로 합쳤다(2026-10-17, 옛 `완료-점검.md` 통합). 지금의 목표는 [0.8.0 로드맵](제안/0.8.0-로드맵-2026-10-16.md)이다. 목표 원문 전체(단계별 지시 1에서 7단계, 직업 문서 A에서 F 항목)는 git 기록의 이 파일 이전 판에 있다.

## 목표 (10월 5일 만든 사람)

플레이어가 어려운 던전을 공략하면서 직업마다 다른 방식으로 승리하고, 스킬 트리·능력치·장비·소모품을 조합해 빌드를 만드는 게임을 완성한다.

- 공개 직업 6개(암살자·파수꾼·사냥꾼·원소술사·마검사·수도승)와 숨겨진 직업 3개를 완성한다.
- 모든 직업과 주요 갈래에 1-3챕터를 통과할 수 있는 검증된 승리 플랜을 마련한다.
- 1챕터를 다시 검증·조정하고, 현재 규칙에 맞는 2·3챕터를 완성한다.
- 2챕터·3챕터 장비 각 200종을 영웅·전설 등급을 포함해 설계·구현한다.
- 소모품, 적과 보스, 경로, 상점, 도박, 패시브, 가혹 모드, 반복 플레이를 하나의 경제와 난이도 체계로 연결한다.
- 현행 통합 기획서와 직업별 상세 기획서를 작성한다.

설계는 **설계 → 반례 검토 → 구현·측정 → 재판단**으로 나눈다. 하지 않은 검토·플레이 테스트를 한 것처럼 적지 않는다. 증거가 부족한 항목은 완료로 표시하지 않는다.

## 0.8.0으로 넘어간 일

1. **사람 플레이:** 규칙 이해·선택의 이유·실수의 납득·다시 하고 싶은 이유. 0.8.0 전체를 만든 뒤 시제품 사이트에서 받는다([로드맵](제안/0.8.0-로드맵-2026-10-16.md)).
2. **화면 낭독기·실기기 접근성 시험**(조건 10).
3. **균형:** 직업 사이 완주 차이, 약한 갈래의 원인, 가혹 모드 목표. 유산·방사형 트리 적용 뒤 다시 잰다.
